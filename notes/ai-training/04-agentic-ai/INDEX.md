# 模块 4: Agentic AI

> 架构设计、评估方法、观测系统、工具调用、规划推理

---

## 本模块捕获内容

- **[架构]** ReAct, Plan-and-Solve, Multi-Agent, Supervisor, CrewAI
- **[评估]** Agent 评测指标、基准测试、人工评估
- **[观测]** Tracing, Logging, 可视化、调试工具
- **[工具]** Function Calling, API 集成、工具选择
- **[规划]** 任务分解、依赖管理、动态规划
