> 实际项目、踩坑记录、工具实践、部署上线

---

## 本模块捕获内容

- **[项目]** 实际完成的 mini agent 项目
- **[工具]** 开发中使用的工具、库、平台
- **[踩坑]** 遇到的问题和解决方法
- **[经验]** 最佳实践、设计模式
- **[部署]** 上线、监控、维护经验

## 快速记录模板

### 项目记录

```markdown
  - 技术栈: {用了什么}
  - 架构图: {简单描述结构}
  - 亮点: {做得好的地方}
  - 代码: {仓库链接}
```

### 工具实践
```markdown
- **[工具]** {工具名称}
  - 用途: {在项目中做什么}
  - 配置: {关键配置项}
  - 集成: {如何接入项目}
  - 评价: {好用吗/值得用吗}
```

### 踩坑记录
```markdown
- **[踩坑]** {问题简述}
  - 环境: {什么场景出现的}
  - 现象: {具体表现}
  - 排查: {怎么定位的}
  - 解决: {最终方案}
  - 预防: {下次如何避免}
```

### 经验总结
```markdown
- **[经验]** {主题}
  - 背景: {什么情况下总结的}
  - 做法: {具体怎么做}
  - 效果: {带来了什么改善}
  - 适用范围: {什么场景通用}
```

### 部署上线
```markdown
- **[部署]** {平台/方式}
  - 方案: {怎么部署的}
  - 监控: {如何观测运行状态}
  - 成本: {运行开销}
  - 优化: {后续改进方向}
```
