V1 术语表（≤10）

先把这十个词钉牢：后面读 Agent.step、Conversation、Workspace 时就不会把 Canvas / 旧 V0 词汇搅进来。

打印友好：浏览器 → 打印 / 另存 PDF。

术语 一句话 文档
Agent 无状态的 reasoning-action 执行器；一次 step() = 一轮循环 agent
Conversation 生命周期 + 状态管理者；按 workspace 分成 Local / Remote conversation
ConversationState 单一可变真相源（元数据 + EventLog） conversation · paper §4.2
Event / EventLog 不可变、只追加的历史；既是记忆，也是观察者总线 events
ActionEvent / ObservationEvent 工具调用 vs 工具结果（可转成 LLM 消息） events
LLM 与提供商无关的模型接口（LiteLLM） llm
Tool (Action→Observation) 带类型的能力，在 workspace 环境里执行 tool-system
Workspace 命令与文件实际跑的地方（Local / Remote / Docker…） workspace
Agent Server 托管远程 Conversation 的 REST/WebSocket 宿主 agent-server
Condenser 压缩历史，给上下文窗口腾地方 agent · condenser
