**CSS 的单位**可以分为两类：**绝对单位**和**相对单位**。

### **常见单位：**

1. **绝对单位**（固定大小，与屏幕分辨率无关）：
   * `px`（像素）：最常用的单位，固定大小，适合精确布局。
   * `cm`（厘米）、`mm`（毫米）、`in`（英寸）：用于打印或特殊场景。
2. **相对单位**（相对于其他值）：
   * `em`：相对于父元素的字体大小。
   * `rem`：相对于根元素（`html`）的字体大小。
   * `%`：相对于父元素的宽度或高度。
   * `vw`、`vh`：相对于视口宽度/高度的 1%。
   * `vmin`、`vmax`：相对于视口宽度和高度中较小/较大的 1%。

***

### `px`**、**`em`**、**`rem`\*\* 和 **`%`** 的区别：\*\*

| **单位** | **描述** | **使用场景** |
| --- | --- | --- |
| `px` | 固定像素，绝对单位，不随屏幕大小或字体大小变化。 | 精确布局，如边框、按钮等固定尺寸。 |
| `em` | 相对单位，基于当前元素的字体大小（继承父元素）。 | 子元素尺寸相对于父元素字体大小变化。 |
| `rem` | 相对单位，基于根元素（`html`）的字体大小（通常默认 16px）。 | 保持全局一致的比例，适合响应式设计。 |
| `%` | 相对单位，基于父元素的尺寸（宽度或高度）。 | 弹性布局，如宽度、高度、内外边距等。 |

***

### **示例：**

```css
html {
  font-size: 16px; /* 根元素字体大小 */
}

.parent {
  font-size: 20px; /* 父元素字体大小 */
}

.child {
  width: 50%;      /* 相对于父元素宽度 */
  font-size: 1em;  /* 20px，继承父元素字体大小 */
  padding: 1rem;   /* 16px，基于根元素字体大小 */
}
```

***

### **总结：**

* `px`：固定尺寸，简单直接。
* `em`：相对父元素，适合局部调整。
* `rem`：相对根元素，适合全局一致性。
* `%`：弹性布局，适合响应式设计。
