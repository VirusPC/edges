# Start with a feature, not a layout
一个应用本质是一堆功能的集合。因此，设计一个应用的第一步：列出该应用需要有哪些功能。布局之类的东西不是应该首先得到关注的部分。功能有了，界面自然就有了。

# Detail comes later
在设计功能的最开始，设计者不应该关注太多细节。

1. Hold the color。然而，当你使用figma等工具时，你可能不得不指定细节。在高保真度环境下，先使用间距、对比度和大小来提升局部内容的重要程度（文字按钮等设为灰色），然后再利用颜色做进一步强调。这样一来，你可以得到一个更清晰、层次感更强和更容易用颜色来增强的界面。
2. Don’t over-invest。低保真度环境下，不要在细节上花太多时间。
