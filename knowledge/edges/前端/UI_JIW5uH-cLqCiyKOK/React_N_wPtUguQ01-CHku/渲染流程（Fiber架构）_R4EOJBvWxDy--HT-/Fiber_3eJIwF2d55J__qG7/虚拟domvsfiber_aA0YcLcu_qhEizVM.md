# 虚拟dom vs fiber



虚拟 DOM 结构和 Fiber 是 React 中两个相关但不同的概念。



• 虚拟 DOM（Virtual DOM）：是对真实 DOM 的轻量级抽象表示，本质是 JavaScript 对象，用于描述 DOM 节点的结构、属性和子节点等信息。它的核心作用是通过对比新旧虚拟 DOM 的差异（Diff 算法），减少直接操作真实 DOM 的开销，提高渲染性能。



• Fiber：是 React 16 之后引入的新架构，它本质上是对虚拟 DOM 的增强和重构。Fiber 不仅包含了虚拟 DOM 所描述的节点信息，还增加了更多用于调度、优先级管理和中断恢复的元数据（如指针、优先级标记等）。其核心目的是实现渲染过程的可中断、可恢复，让 React 能更好地处理高优先级任务（如用户输入），避免渲染阻塞主线程。



简单来说，Fiber 是在虚拟 DOM 基础上，为了优化渲染调度而设计的更复杂的数据结构，虚拟 DOM 是 Fiber 的一部分功能基础，二者不能等同。
