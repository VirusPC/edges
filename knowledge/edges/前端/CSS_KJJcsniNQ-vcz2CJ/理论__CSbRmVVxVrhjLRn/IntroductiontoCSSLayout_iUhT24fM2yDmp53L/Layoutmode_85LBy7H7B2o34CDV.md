# Layout mode

一个 CSS **layout mode** ，有时称为 **layout** ，是一个基于 box 和它们的兄弟以及祖先 box 的交互方式，来决定 box 自己的位置和大小的算法。它们有以下几种：



+ [_Normal flow_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Flow_Layout)_ ——_ <font style="color:#333333;">所有元素都是 normal flow 的一部分，直到你采取措施将其从 flow 中移出。 Normal flow 包括 block layout 和 inline layout。前者用于布置诸如段落之类的 box，而后者则用于布置诸如文本之类的 inline 项目。</font>
+ [_Table layout_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Table)_ _—— 被设计来布局 table。
+ _Float layout_ —— <font style="color:#333333;">旨在使项目将自身放到左边或右边，并使得其余 normal flow 中的内容围绕着它</font>
+ [_Positioned layout_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Positioning)_ —— _设计来放置不需要与其他元素有太多交互的元素。
+ [_Multi-column layout_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Columns)_ _—— <font style="color:#2E3033;">专为像在报纸上那样在专栏中安排内容而设计的。</font>
+ [_Flexible box layout_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Flexible_Box_Layout)_ _—— <font style="color:#2E3033;">设计来布局复杂的页面，可以平滑地调整大小。</font>
+ [_Grid layout_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Grid_Layout)_ —— _设计来相对固定的网格进行布局。



**注意：**不是所有的 CSS 属性都适用于所有的 layout mode。大部分属性只适用于他们中的一两个，对其他的 layout mode 无效。
