# Taxonomy
1. Similarity-based qureying（相似性查询）[1]
    1. Pattern existence query. Find the time series data with certain patterns.
    2. Shape match query. Look for the time series data that have similar movement  shapes.
2. Exact match? timebox?



# Query Interfaces
1. Query Sketch:  allows users to sketch a graph freehand, then view stocks whose price histories match the sketch.  Search by example.
2.  A visual digital library approach for time-oriented scientific primary data [3]. Search by example.
3. MIMSY: GUI, text box,  drop-down list etc.0
4. Timebox: A set of query tools.
5. Shape Search
