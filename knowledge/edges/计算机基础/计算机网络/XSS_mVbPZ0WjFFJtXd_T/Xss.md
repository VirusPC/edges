以下是三种 XSS 攻击的 **核心对比**，按原理、场景、解决方案分类整理：

***

### 📊 **XSS 攻击类型对比表**

| **类型** | **反射型 XSS** | **存储型 XSS** | **DOM 型 XSS** |
| --- | --- | --- | --- |
| **原理** | 恶意脚本通过 **URL 参数注入**，服务端直接返回未编码内容到响应中 | 恶意脚本**存储到数据库/文件**，每次页面加载时自动执行 | 前端 **JavaScript 动态修改 DOM** 时注入未编码内容 |
| **触发方式** | 用户点击构造的恶意链接 | 用户访问**正常页面**（如评论区、消息中心） | 用户访问前端路由或执行特定 JS 操作 |
| **数据流** | `URL → 服务端 → 响应 → 浏览器` | `输入框 → 数据库 → 页面加载 → 浏览器` | `URL/前端输入 → JS 操作 DOM → 浏览器` |
| **持久性** | ❌ 一次性（依赖用户点击） | ✅ 长期存在（直到数据被清除） | ❌ 不存储（依赖每次访问触发） |
| **典型场景** | 1. 搜索框结果页   2. 错误消息提示   3. URL 重定向参数 | 1. 用户评论/留言板   2. 个人资料昵称   3. 文件上传名 | 1. 前端路由参数（`#`）   2. `document.write()`   3. `innerHTML` 动态渲染 |
| **危害示例** | 窃取当前用户 Cookie | 所有访问者自动执行恶意脚本 | 劫持前端逻辑窃取表单数据 |
| **解决方案** | **1. 输出编码**   - HTML 实体化（`< → &lt;`）   **2. 输入校验**   - 过滤 `<>'"/` 等符号 | **1. 存储前过滤+编码**   - 富文本用白名单（如 DOMPurify）   **2. CSP 防护**   - 禁止内联脚本：`Content-Security-Policy: script-src 'self'` | **1. 安全 DOM 操作**   - 用 `textContent` 替代 `innerHTML`   **2. 前端输入验证**   - 对 `location.hash` 等来源消毒 |

***

### 🛡️ **通用防御措施（全类型适用）**

1. **内容安全策略（CSP）**

```http
Content-Security-Policy: default-src 'self'; script-src 'nonce-{随机值}';
```

```
- 禁止内联脚本和外部未知脚本
```

2\. **HttpOnly Cookie**

```java
// 服务端设置 Cookie
response.setHeader("Set-Cookie", "sessionId=xxx; HttpOnly");
```

```
- 阻止 JavaScript 读取敏感 Cookie
```

3\. **X-XSS-Protection**（历史遗留，现代浏览器已弃用，仅兼容旧设备）

```http
X-XSS-Protection: 0  // 明确关闭旧机制
```

4. **框架自动防护**
   * React/Vue/Angular 默认转义插值内容（除非使用 `v-html`/`dangerouslySetInnerHTML`）

***

### ⚠️ **各类型额外注意点**

| **类型** | **关键陷阱** | **必做检查** |
| --- | --- | --- |
| **反射型** | 重定向参数（`?redirect=`）需**白名单校验** | 测试所有 URL 参数能否注入 `"><svg onload=alert(1)>` |
| **存储型** | 富文本编辑器需**严格白名单**（如仅允许 `p, b, img[src]`） | 审计所有用户输入存储点（包括 API 和第三方存储） |
| **DOM 型** | 避免 `eval()`/`setTimeout('动态代码')` | 代码扫描：查找 `innerHTML`/`document.write()` |

***

### 💎 **总结：黄金防护原则**

1. **输入过滤 ≠ 安全** → **输出编码**才是最后防线！
2. **前端验证可绕过** → 服务端必须二次校验！
3. **“我的网站很小”** → XSS 机器人全天候扫描全网表单！

> **一句话决策树**：
>
> * 内容输出到 HTML → **HTML 实体编码**
> * 内容输出到属性 → **Attribute 编码**（`" → &quot;`）
> * 内容输出到 JS → **JS 编码**（`\x3cscript\x3e`）
> * 内容输出到 URL → **URL 编码**（`%3Cscript%3E`）

通过分层防御彻底阻断 XSS 攻击链 🔐
