Python 中方括号和点的使用规则非常清晰

## 核心差异

Python 严格区分两种访问模式:

| 概念                  | 访问方式      | 用途                                                                                  |
| ------------------- | --------- | ----------------------------------------------------------------------------------- |
| **属性** (attributes) | `.name`   | 访问对象的固定结构成员 [langchain](https://docs.langchain.com/oss/python/langchain/quickstart) |
| **键值对** (key-value) | `["key"]` | 访问动态数据映射 [langchain](https://docs.langchain.com/oss/python/langchain/quickstart)    |

avaScript 的设计哲学是:**对象本质上就是键值映射** (原型链上的动态属性包)。所以 `obj.key` 和 `obj["key"]` 完全等价。而 **Python、Java、Go** 都明确区分:
- **静态结构**(类的属性/字段)用点语法
- **动态数据**(字典/映射)用索引语法

|语言|对象属性|动态映射|特点|
|---|---|---|---|
|**Python**|`.attr`|`["key"]`|严格区分 [langchain](https://docs.langchain.com/oss/python/langchain/quickstart)|
|**Java**|`.field`|`.get("key")`|严格区分,Map 用方法|
|**Go**|`.Field`|`["key"]`|严格区分|
|**TypeScript**|`.prop`|`["key"]` 或 `.prop`|**不区分**,对象就是哈希表|
|**JavaScript**|同 TS|同 TS|同 TS|
## 使用方括号 `[]`

**1. 字典访问键值**

python

`result["messages"]  # 访问字典的 key config["configurable"]["thread_id"]  # 嵌套字典`

**2. 列表/序列索引**

python

`result["messages"][-1]  # 获取列表最后一个元素 text[0:10]  # 切片操作`

**3. 动态属性名**

python

`key = "messages" result[key]  # 变量作为键名`

## 使用点 `.`

**1. 对象属性访问**

python

`result["messages"][-1].content_blocks  # 访问对象的属性 agent.invoke(...)  # 调用对象的方法`

**2. 模块/类成员**

python

`urllib.request.Request  # 访问模块的子模块和类`

## 混合使用示例

从文档中的代码:[langchain](https://docs.langchain.com/oss/python/langchain/quickstart)

python

`print(result["messages"][-1].content_blocks)`

这行代码展示了混合使用:

- `result["messages"]` - 字典访问,获取 messages 键的值(列表)
    
- `[-1]` - 列表索引,获取最后一个元素(对象)
    
- `.content_blocks` - 对象属性访问
    

## 快速判断规则

|数据类型|访问方式|示例|
|---|---|---|
|字典 (dict)|`["key"]`|`result["messages"]` [langchain](https://docs.langchain.com/oss/python/langchain/quickstart)|
|列表 (list)|`[index]`|`messages[-1]` [langchain](https://docs.langchain.com/oss/python/langchain/quickstart)|
|对象实例|`.attribute`|`message.content_blocks` [langchain](https://docs.langchain.com/oss/python/langchain/quickstart)|
