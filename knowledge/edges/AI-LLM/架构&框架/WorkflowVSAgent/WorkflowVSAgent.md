# Workflow VS Agent

[https://www.zhihu.com/question/1896707093580448857/answer/1919367811278550553?share_code=DNkTU1DCd4Al&utm_psn=1928389206914339982](https://www.zhihu.com/question/1896707093580448857/answer/1919367811278550553?share_code=DNkTU1DCd4Al&utm_psn=1928389206914339982)



1. **Workflow (工作流)**：
    - **是什么**：一套**预定义、固定步骤**的业务流程或任务序列。
    - **核心**：像**自动化的流程图或说明书**。它规定“先做什么，再做什么，遇到情况A走左边，遇到情况B走右边”。
    - **关键特点**：**流程驱动、被动执行**。需要外部触发（如事件、定时、人工启动），然后严格按照设定好的路径一步步走，**几乎没有自主决策能力**。
2. **Agent (智能体/代理)**：
    - **是什么**：一个具有**感知、决策、执行能力**的**自治软件实体**。
    - **核心**：像一个**有目标、会自己想办法的员工**。它知道“要达成什么目标”，然后**自己观察环境、分析信息、做决定、采取行动**去实现目标。
    - **关键特点**：**目标驱动、主动决策**。它能根据环境和信息变化，**自主判断下一步该做什么**，甚至调整策略，**不需要每一步都预先设定好**。

**二者最核心的区别**：

+ **驱动力与决策方式**：
    - **Workflow**: **流程驱动**。下一步做什么由**预先编排好的流程步骤**决定。（被动执行）
    - **Agent**: **目标驱动**。下一步做什么由**它自己为实现目标而做出的决策**决定。（主动决策）
+ **灵活性**：
    - **Workflow**: **僵化**。流程固定，环境或需求变了，流程就得重新设计修改。
    - **Agent**: **灵活**。能根据新情况、新信息**动态调整策略和行为**去达成目标。

**简单比喻**：

+ **Workflow** 像 **工厂流水线机器**：设定好程序，来一个零件就按固定工序一步步处理（拧螺丝 -> 贴标签 -> 打包），遇到异常可能就卡住或报错。
+ **Agent** 像 **独立工作的员工**：老板说“把这个项目搞定”（目标）。员工自己查资料（感知）、想方案（决策）、找资源、做调整（执行），遇到问题会想办法解决，最终达成目标。

**一句话总结区别**：  
**Workflow 是按固定剧本演戏的演员，Agent 是为达成目标自己写剧本的导演兼演员。**  
（机器不会思考，员工必须思考）
