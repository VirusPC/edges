#### 定义与类型
知识是智能体执行任务和决策的基础，由LLM通过大规模预训练数据获取并存储于模型参数中。知识可分为以下几类：[137][140]

1. **语言学知识**：  
包括语法、语义和多语言能力，使智能体能够理解和生成复杂语言结构。[142][147]
2. **常识知识**：  
涉及日常生活中的基本事实和逻辑，例如“雨天需要带伞”，帮助智能体处理隐含信息。[148][150]
3. **专业领域知识**：  
针对特定领域（如编程、医学、数学）的知识，用于解决专业问题。[151][153]

#### 问题与挑战
1. **知识过时或错误**：
    - LLM在训练过程中获取的知识可能随着时间推移变得过时，甚至从一开始就存在错误。[155]
    - 重新训练模型是解决知识问题的一种方式，但需要大量数据、时间和计算资源，同时可能引发“灾难性遗忘”（即新知识覆盖旧知识）。[156]
2. **幻觉问题**：
    - LLM可能生成与事实不符的内容（幻觉），导致结果与真实信息冲突。[224][225]
    - 幻觉问题是限制LLM在高要求事实任务中广泛应用的关键原因。

#### 解决方案
1. **知识更新与编辑**：
    - 研究者尝试通过定位和修改模型中存储的具体知识来解决错误知识问题。
    - 这种方法能够部分编辑事实性知识，但其内部机制仍需进一步研究。[157][158][159]
2. **幻觉检测与评估**：
    - 提出衡量幻觉程度的指标，为开发者提供参考以评估LLM输出的可信性。[160]
3. **外部工具集成**：
    - 通过整合外部工具（如检索系统或知识库），帮助LLM验证或补充知识，避免生成错误内容。[161][162][226]
4. **提示词工程**

#### 总结
LLM在知识存储与利用方面表现出色，但面临知识过时、错误以及幻觉问题的挑战。通过知识编辑、幻觉检测和外部工具集成等方法，可以有效改善模型的知识准确性和可信度，推动其在事实性任务中的应用。

知识是LLM智能体的核心能力，通过不断优化存储、更新和验证机制，提升知识的准确性与应用广度。
