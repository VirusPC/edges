---

**TF-IDF**（Term Frequency-Inverse Document Frequency）是一种用于**信息检索**与**文本挖掘**的经典加权技术，用于**评估一个词在文档中的重要程度**。其核心思想是：**词的重要性随其在文档中的出现次数正比增加，但随其在语料库中的普遍性反比下降**。

计算出词在一个文档中的重要性分数。

对于每个文档，会生成一个向量。一个查询往往由多个词组成，也是向量。对二者做余弦相似度计算。

***

### **一、TF-IDF 的计算公式**

分为两个部分组合而成：

#### **1. 词频（TF - Term Frequency）**

> 衡量词在当前文档中的出现频率。\
> \[\
> \text{TF}(t, d) = \frac{\text{词 } t \text{ 在文档 } d \text{ 中的出现次数}}{\text{文档 } d \text{ 的总词数}}\
> ]\
> **例如**：文档 `d` 包含 100 个词，“苹果”出现 5 次 → `TF("苹果", d) = 5/100 = 0.05`

#### **2. 逆文档频率（IDF - Inverse Document Frequency）**

> 衡量词在整个语料库中的普遍性（常见词如“的”重要性低）。\
> \[\
> \text{IDF}(t, D) = \log \left( \frac{\text{语料库中文档总数 } N}{\text{包含词 } t \text{ 的文档数} + 1} \right)\
> ]\
> **例如**：语料库有 1000 篇文档，“苹果”在 50 篇中出现 → `IDF("苹果") = log(1000/50) ≈ 3.0`

#### **3. TF-IDF 最终值**

$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \text{IDF}(t, D)$

上例结果：`TF-IDF("苹果", d, D) = 0.05 × 3.0 = 0.15`

***

### **二、TF-IDF 的直观意义**

| **场景** | **TF** 表现 | **IDF** 表现 | **TF-IDF 结果** |
| --- | --- | --- | --- |
| **文档高频词** | 高 ✅ | - | - |
| **语料库罕见词** | - | 高 ✅ | - |
| **高频 + 罕见**（如专业术语） | 高 ✅ | 高 ✅ | **极高** ★ 重要词 |
| **高频 + 常见**（如“的”） | 高 ✅ | 低 ❌ | **被抑制** ▼ 无意义词 |

***

### **三、TF-IDF 的典型应用**

1. **搜索引擎排序**
   * 用户搜索 `"苹果手机"` → 计算各网页中 `"苹果"` 和 `"手机"` 的 TF-IDF 值，优先返回权重高的页面。
2. **文本相似度计算**
   * 将文档表示为 TF-IDF 向量（维度=所有词），通过 **余弦相似度** 比较相似性。
3. **关键词提取**
   * 选取 TF-IDF 值最高的词作为文档关键词（如 `["人工智能", "算法", "模型"]`）。
4. **文本分类/聚类**
   * 作为特征输入机器学习模型（如 SVM、朴素贝叶斯）。

***

### **四、Python 代码示例**

```python
from sklearn.feature_extraction.text import TfidfVectorizer

# 语料库示例
corpus = [
    "苹果 是 一种 水果",        # 文档1
    "苹果 公司 发布 新 手机",   # 文档2
    "水果 市场 销售 苹果 和 香蕉" # 文档3
]

# 计算 TF-IDF 矩阵
vectorizer = TfidfVectorizer(token_pattern=r"(?u)\b\w+\b") 
tfidf_matrix = vectorizer.fit_transform(corpus)

# 输出词表及权重
print("词表：", vectorizer.get_feature_names_out())
print("TF-IDF 矩阵：\n", tfidf_matrix.toarray())
```

**输出**：

```plain
词表： ['一种' '公司' '发布' '市场' '手机' '是' '水果' '苹果' '香蕉' '销售' '和' '新']
TF-IDF 矩阵（文档2示例）：
 [0.    0.51  0.51  0.    0.51  0.    0.    0.39  0.    0.    0.    0.51]
# 解释：文档2中 "公司"、"发布"、"手机"、"新" 的 TF-IDF 值高
```

### **五、TF-IDF 的优缺点**

| **优点** | **缺点** |
| --- | --- |
| ✅ 直观易解释 | ❌ 无法捕捉词序（同词袋模型） |
| ✅ 过滤常见词（IDF 机制） | ❌ 无法表达语义（如“苹果”水果 vs 品牌） |
| ✅ 计算高效（适合大规模文本） | ❌ 依赖语料库统计（静态权重） |

***

### **六、与深度学习的对比**

* **TF-IDF**：基于统计规则，可解释性强，适合轻量级任务。
* **词嵌入（Word2Vec/BERT）**：基于神经网络，捕捉语义和上下文，但需大量数据和算力。

> **实际应用**：常将 TF-IDF 作为基线模型，或与深度学习结合（如 BERT 输入层加入 TF-IDF 加权）。

***

**总结**：

> TF-IDF 是 **NLP 的基石技术**，通过 `TF × IDF` 的简单设计，高效识别关键词语义信号。尽管被深度学习部分取代，其在工业界（搜索引擎、推荐系统）仍是**不可或缺的预处理工具**。
