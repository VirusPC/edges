## 定义与作用
记忆在LLM智能体中用于存储过去的观察、思考和行动序列，类似于人类大脑通过回顾经验来制定策略和决策。记忆机制帮助智能体处理连续任务，并适应复杂环境。[228][229]

## 问题与挑战
1. **历史记录长度限制**：
    - 随着交互循环的扩展，历史记录可能超出LLM的Transformer架构长度限制，导致部分内容被截断。[163][165]
2. **记忆提取困难**：
    - 随着积累的历史信息增多，智能体难以快速提取相关记忆，可能导致上下文不一致或响应偏离当前任务。[170][174]

## 解决方案
1. **Methods for better memory capability.**
    1. **提高Transformer的长度限制**：
        * 通过文本截断、输入分段或重点提取等方法优化处理长序列的能力。
        * 修改注意力机制以降低复杂度，从而支持更长的序列输入。[164][165][167]
    2. **记忆总结**：
        1. **基于提示的总结**：
            + 使用设计好的提示（prompts）对记忆进行简要整合，生成简洁的总结。[168]
        2. **反思式总结**：
            + 通过反思过程提取记忆中的关键内容，创建精炼的记忆表示。[22][239]
        3. **层次化总结**：
            + 将对话内容分层处理，生成每日快照和总体总结，便于信息组织与检索。[170]
        4. **环境反馈转化**：
            + 将环境中的反馈信息转化为文本形式，帮助智能体更好地理解上下文并应用于未来任务。[169]
        5. **多智能体环境中的通信捕获**：
            + 在多智能体场景中，记录并保留智能体间通信的关键元素，以支持后续任务。[171]
    3. **记忆压缩**：
        1. **嵌入向量表示**：
            + 将记忆内容转化为低维嵌入向量，便于快速检索和匹配。
            + 应用场景包括存储对话历史、计划或任务步骤。[170][172][174]
        2. **三元组表示**：
            + 将句子转化为三元组（如“主语-谓语-宾语”），以结构化形式存储关键信息。
            + 这种方法可以减少存储空间并提高信息检索的准确性。[173]
            + [Manus](https://manus.im/zh-cn/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus)采用了另一种结构化方式，而且“**可恢复**”![1754203351477-498670fb-af4b-46a6-a310-0c69d18200d8.png](./img/FbjcRX_D9kKk2yLC/1754203351477-498670fb-af4b-46a6-a310-0c69d18200d8-736952.png)
        3. **数据对象化**：
            + 将记忆视为独立的数据对象，允许灵活操作，如移动、编辑或删除记忆。
            + 例如，Memory Sandbox中通过交互式管理记忆对象，提升记忆的可操作性。[176]
2. **Methods for memory retrieval.**
    1. **记忆检索机制**：
        * 自动检索：根据记忆的“最近性”、“相关性”和“重要性”评分，优先选择高分记忆。[22][170]
        * 交互式检索：允许用户编辑、删除或合并记忆对象，使记忆内容更贴合用户需求。[176][175]

## 总结
记忆是LLM智能体实现长期任务处理和动态适应的关键能力，但面临长度限制和提取效率问题。通过优化Transformer架构、记忆总结与压缩，以及引入有效的检索机制，智能体能够更高效地管理记忆，从而提升任务完成质量和交互体验。
