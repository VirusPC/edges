【讨论主题】
Project Memory 的一个核心作用：跨 Agent / 账号切换时继承经验。

【主要结论】
- Project Memory 填出来之后，一个作用是：当 Claude Code 账号被封，或某个 Agent 达到限额时，可以很方便地切换到其他 Agent 继续工作。
- 切换后应能继承所有已沉淀的经验（项目记忆不绑死在单一 Agent / 账号上）。

【认知更新】
- 记忆层的价值不只是「当前会话更好用」，还包括容灾与连续性：限额、封号、换工具时工作不中断。

【行动指南】
- 设计 project-memory 时显式支持「跨 Agent 可读可续」：记忆落在项目侧，不依赖单个 runtime / 账号会话。
- 评估与可扩展 memory type、assets 等方案时，以「换 Agent 仍能接着干」作为验收标准之一。
