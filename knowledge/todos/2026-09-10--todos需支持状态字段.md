【讨论主题】
todos 需要统一状态字段，以闭环「开发完后修改 TODO 状态」。

【主要结论】
- 既定工作流：idea → Todo 记录员落盘 → 专家细聊 → Cursor Cloud Agent 开发 → 改 TODO 状态。
- 当前 `knowledge/todos/` 条目缺少统一、可改的状态字段，收口环节还不成立。

【认知更新】
- 只有「写下 todo」不够；状态机（如 open / discussing / building / done）才是跨 Agent 接力的契约。

【行动指南】
- 为 todos 约定状态字段与取值（至少覆盖：待聊 / 细聊中 / 开发中 / 已完成，或等价英文）。
- 明确谁在何时改状态（Todo 记录员 / 专家 / Cloud Agent 完成后回写）。
- 可选：洗存量 todos，补上默认状态（如 open）。
