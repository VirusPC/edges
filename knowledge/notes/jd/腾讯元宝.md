## 

Agent架构工程师

腾讯 不需要融资北京·经验不限·本科

30-60K·15薪

### 职位详情

岗位职责 1. 负责元宝在线产品的 Agent 系统整体架构设计与演进，包括Agent Runtime、Tool/Memory/Context 抽象、多 Agent 协作模式、Human-in-the-loop等。 2. 与算法/产品/业务高频密切合作，结合产品功能、模型能力边界与架构约束，实现 Agent 产品的整体架构方案设计。 3. 持续探索、研究并引入新的框架和 Agent 技术范式。 
岗位要求 1. 本科及以上，计算机/自动化/AI 等相关背景，具备扎实工程基础 2. 熟练至少一门主流语言（Python / TypeScript / Go 等），能熟练使用主流ai coding工具。 3. 了解 LLM 与 Agent 基本技术原理和常见范式。 4. 具备良好的产品sense和团队沟通协作能力。
