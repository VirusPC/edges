# 2026-09-26--Mac遥控其它主机-Windows-App与RDP

> **今晚为何重要**：有线局域网 + Tailscale 解决了「包能到」，但用户真正要的是 **从 MacBook 看到别人的屏幕**。当晚澄清：Mac↔Mac 用屏幕共享；Mac↔Windows 用 **Windows App（原 Microsoft Remote Desktop）+ 本机开 RDP**；并启用了 `4070ts-win11` 的远程桌面。账号怎么填、主机名用短名还是 IP，都直接决定明天能不能连上。

## 背景

- 方案讨论 **00:08**；专业版与 Windows App **00:21–00:25**；开 RDP **00:25**；登录字段 **00:30**。
- 助手：IT资产管理。
- 用户原文：「**我的macbook如何操控其他主机的屏幕？macmini是可以的，tailscale+screen sharing。其他的怎么办？**」「**我这个win是专业版？**」「**好像用 windowsAPP 连接就行？**」「**我打开了么**」「**我windowsapp远程登陆 4070ts，账号密码填啥**」。

## 主题

这场在打通从笔记本看对端屏幕的入口：按系统选协议（Mac 屏幕共享、Windows 用 Windows App + 本机远程桌面），确认专业版许可并启用服务，用系统账户密码与短名收藏，并减少自动锁屏打断远控。

- 难点：「能远程登录命令行」不等于「能看屏幕」；协议与客户端要按对端系统分开选。
- 难点：Windows 远程桌面依赖专业版许可、本机已启用、防火墙与账户密码；家庭版没有完整主机功能。
- 难点：PIN 通常不能直接当远程桌面密码；短 MagicDNS 名对远控收藏极其重要。
- 难点：统一走基于身份的组网触达，不把远程桌面直接暴露到公网。

## 过程

### 分系统协议（00:08）

- Mac mini：屏幕共享 / `vnc://macmini`。
- Windows：开「远程桌面」；Mac 用 **Windows App** 连 MagicDNS 短名或组网触点。
- Ubuntu：GNOME Remote Desktop / xrdp / VNC（当晚未强制落地）。
- NAS：优先网页管理。
- 统一：走 Tailscale，不公网裸奔。
- 取舍：同平台用系统自带屏幕共享；跨到 Windows 用远程桌面客户端；不把所有机器强行套同一协议。

## 所学

- 「能远程登录命令行」不等于「能看屏幕」。
- Windows App 连的是远程桌面协议，依赖专业版许可、本机已启用、防火墙与账户密码。
- 短 MagicDNS 名对远控收藏极其重要。
- PIN 通常不能直接当远程桌面密码，要用系统账户密码。

取舍补充：

- 协议选择：Mac 屏幕共享 / Windows App+RDP / Ubuntu 多种桌面方案 / NAS 网页——按系统选，不强行统一；Ubuntu 当晚不落地。
- 触达路径：公网裸奔 vs 走 Tailscale——认后者。
- 只要命令行时：不必强开屏幕，走 OpenSSH 或本机执行即可。
- 凭证：PIN vs 系统账户密码——远程桌面认系统账户密码。

## 行动指南

### 主题行动指南

#### 背景

组网与有线已经让包能到对端，但操作者需要从笔记本或手机看到对端桌面；同平台往往有系统自带屏幕共享，跨到 Windows 则要远程桌面客户端配合本机服务。

#### 核心问题

如何稳定打开屏幕远控入口：选对协议与客户端、确认版本许可与服务已启用、用正确的账户字段与短名收藏，并减少远控过程被自动锁屏打断。

#### 核心解决方案

按顺序做：

1. 按对端系统选协议：同平台优先系统自带屏幕共享；对 Windows 用远程桌面客户端 + 本机远程桌面服务。不做：所有机器强行套同一协议。
2. 确认 Windows 版本具备主机侧远程桌面能力，并启用服务与防火墙放行。家庭版无完整主机功能时不要硬开。
3. 统一走基于身份的组网触达，不把远程桌面直接暴露到公网。不做：公网裸奔 RDP。
4. 收藏短主机名；登录用系统账户密码，不用 PIN。
5. 若只要命令行，走已开通的远程命令行或本机执行通道，不必强开屏幕。
6. （可选）关闭或放宽自动锁屏，减少远控会话被打断。

#### 验收标准

以后按本主题执行时，下列全部成立才算完成：

- 从约定客户端能按短名进入对端桌面（若本轮需要控屏）。
- Windows 侧远程桌面已启用且服务在跑；版本具备主机功能。
- 登录使用系统账户密码成功；未误用 PIN 作为唯一凭证。
- 连接路径走组网，而非公网裸奔。

### 细节与其他

#### 若连不上 Windows 桌面

则：

1. 确认远程桌面已启用（`fDenyTSConnections=0`，相关服务在跑）。
2. 确认双方 Tailscale 在线。
3. 查用户名是否需带电脑名前缀（`Cheng Peng` / `DESKTOP-K3G8QJ2\Cheng Peng` / `.\Cheng Peng`）。
4. 确认用的是本机账户密码而非 PIN。
5. 核对短名是否已改成 `4070ts-win11`。

不做：把 PIN 当 RDP 密码反复试。

#### 若只要命令行

则：用 OpenSSH 或 Grok Bot 本机执行即可，不必开 Windows App。当时未比较其它远控命令行客户端。

#### 若要控 Mac mini 屏幕

则：继续屏幕共享 / `vnc://macmini`（经 Tailscale）。不做：改用 Windows App 去连 Mac。

#### 若要控 Ubuntu 桌面

则：当晚未强制落地（GNOME Remote Desktop / xrdp / VNC 仅讨论）。另开专题时仍走 Tailscale，勿公网裸奔。相关可选项当晚未选定其一。

#### 若远控常被锁屏打断

则：在 Windows 侧关闭或放宽自动锁屏（当晚 00:32–00:36 已处理过一轮）。
