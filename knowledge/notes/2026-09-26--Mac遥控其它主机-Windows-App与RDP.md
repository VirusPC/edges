## 所学

- 「能远程登录命令行」不等于「能看屏幕」。
- Windows App 连的是远程桌面协议，依赖专业版许可、本机已启用、防火墙与账户密码。
- 短 MagicDNS 名对远控收藏极其重要。
- PIN 通常不能直接当远程桌面密码，要用系统账户密码。

## 行动指南

### 主题行动指南

#### 背景

组网与有线已经让包能到对端，但操作者需要从笔记本或手机看到对端桌面；同平台往往有系统自带屏幕共享，跨到 Windows 则要远程桌面客户端配合本机服务。

#### 核心问题

如何稳定打开屏幕远控入口：选对协议与客户端、确认版本许可与服务已启用、用正确的账户字段与短名收藏，并减少远控过程被自动锁屏打断。

#### 核心解决方案

按顺序做：

1. 按对端系统选协议：同平台优先系统自带屏幕共享；对 Windows 用远程桌面客户端 + 本机远程桌面服务。
2. 确认 Windows 版本具备主机侧远程桌面能力，并启用服务与防火墙放行。
3. 统一走基于身份的组网触达，不把远程桌面直接暴露到公网。
4. 收藏短主机名；登录用系统账户密码，不用 PIN。
5. 若只要命令行，走已开通的远程命令行或本机执行通道，不必强开屏幕。
6. （可选）关闭或放宽自动锁屏，减少远控会话被打断。

#### 验收标准

以后按本主题执行时，下列全部成立才算完成：

- 从约定客户端能按短名进入对端桌面（若本轮需要控屏）。
- Windows 侧远程桌面已启用且服务在跑；版本具备主机功能。
- 登录使用系统账户密码成功；未误用 PIN 作为唯一凭证。
- 连接路径走组网，而非公网裸奔。

### 细节与其他

#### 若连不上 Windows 桌面

则：

1. 确认远程桌面已启用（`fDenyTSConnections=0`，相关服务在跑）。
2. 确认双方 Tailscale 在线。
3. 查用户名是否需带电脑名前缀（`Cheng Peng` / `DESKTOP-K3G8QJ2\Cheng Peng` / `.\Cheng Peng`）。
4. 确认用的是本机账户密码而非 PIN。
5. 核对短名是否已改成 `4070ts-win11`。

#### 若只要命令行

则：用 OpenSSH 或 Grok Bot 本机执行即可，不必开 Windows App。

#### 若要控 Mac mini 屏幕

则：继续屏幕共享 / `vnc://macmini`（经 Tailscale）。

#### 若要控 Ubuntu 桌面

则：当晚未强制落地（GNOME Remote Desktop / xrdp / VNC 仅讨论）。另开专题时仍走 Tailscale，勿公网裸奔。

#### 若远控常被锁屏打断

则：在 Windows 侧关闭或放宽自动锁屏（当晚 00:32–00:36 已处理过一轮）。
