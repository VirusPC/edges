# 2026-09-27--Win11管理员通道OpenSSH与手机远控

> **今晚为何重要**：前一日只设计了「当面一次 UAC → OpenSSH + GrokBot-Admin」；当晚把通道真正落地，并打通 iPhone 经 Tailscale 用 Windows App 看屏。人不在机旁时，聊天确认后即可触发 SYSTEM 任务，SSH 也能进机。

## 背景

- 主机：Windows 11 专业工作站版，已就地升级到 **25H2**（本机名仍为长名；Tailscale 短名此前定稿）。专用设备助手负责本机运维。
- 前序：[支线笔记](./2026-09-26--支线-企业WiFi-Comet收藏夹-Win助手与OpenSSH-灯光启动项.md)写明管理员通道「设计了但未全部落地」；[全网 Tailscale SSH](./2026-09-26--全网Tailscale-SSH开通与4070ts改名.md)写明 Windows **无** Tailscale SSH 服务端，应改走 OpenSSH / RDP。
- 用户意图：「详细说下方案」→「来吧，我准备好了」→ 中途外出吃饭 → 用 iPhone 远控回机继续 → SSH 实测成功 →「整理份笔记」。
- 同场旁支：Windows 用激活码激活成功；ChatGPT 开机启动项复查（实际已自启）；iPhone Windows App 列表不跟 Mac 同步。

## 主题

这场在把 Windows 的「远程代跑 + 看屏」从口头方案落成可复用通道：OpenSSH 服务端、SYSTEM 计划任务运行器、以及手机经私网连远程桌面；并厘清能力包装挂死时的备选与远控初始化失败的常见原因。

- 难点：Windows 不能 `tailscale set --ssh`，必须本机 OpenSSH；第一次提权仍须当面（或远控能点）UAC。
- 难点：`Add-WindowsCapability` 装 OpenSSH 可长时间无进度条且挂死；winget 备选若只在「抛异常」后才触发，会干等。
- 难点：iPhone Windows App 与 Mac 的主机列表不共享；卡在 Initializing 时常是手机 Tailscale 离线，不是本机 RDP 坏了。
- 难点：管理员通道等于「可写 pending 脚本 + 触发 SYSTEM 任务」——权限极大，须聊天确认，且 22 端口不宜裸对公网。

## 过程

### 傍晚 激活与启动项（时刻约 18:30–18:45）

- 用户称 Windows 尚未激活；合法排查结论：当前为 **KMS 客户端 GVLK**，局域网 / Tailscale 无可达 KMS，无 OEM / 数字权利可恢复。曾清掉指向 `127.0.0.2` 的假 KMS 残留（只清理，不装破解）。
- 用户拒绝走破解路线后，自行使用激活码激活成功。
- 用户问 ChatGPT 为何没开机启动：复查启动文件夹仍有 `ChatGPT.lnk` 与 `Grok Bot.lnk`（约 9 月 26 日写入），25H2 **未**抹掉；当次登录约数十秒后进程已起。取舍：配置完好则不重写快捷方式。

### 约 18:48–18:54 方案复述

- 用户问「怎么配 SSH」→ 复述两层：**OpenSSH Server**（远程命令行）+ **`GrokBot-Admin`**（`C:\ProgramData\GrokBot` 下 pending 作业 → SYSTEM 任务）。第一次须当面 UAC；之后聊天确认再触发。
- 对比 Linux 侧 Tailscale SSH：Windows 官方无该服务端——认 OpenSSH / RDP，不硬套 `set --ssh`。

### 约 18:52–19:14 安装与挂死、备选、完成

- 用户：「来吧，我准备好了。」拉起一次性脚本；UAC 通过。
- 日志显示目录 / ACL / `run-job.ps1` 先写好，随后 `Add-WindowsCapability OpenSSH.Server` 自约 18:57 起日志冻结；后台可见组件存储工人进程，界面常无显眼下载窗口。用户感觉「没进展」——属能力包装静默期，但本次实际挂住。
- 脚本设计上 winget（如 Microsoft.OpenSSH.Preview）仅在能力包**抛异常**后才走，**不处理挂死** → 长时间无 `sshd`、无 `GrokBot-Admin`。
- 用户外出吃饭：停止新弹 UAC；桌面留下 `finish-min.ps1` / `launch-finish-min.bat` 待回机。
- 约 19:14：收尾完成。验证：`sshd` Running 且开机自启、22 端口监听、任务 `GrokBot-Admin` Ready、DONE 标记 OK。用户回机后未再看到 UAC——因通道已在外出期间跑通。

### 约 19:15–19:24 手机远控与 SSH 实测

- 用户问 iPhone 控 Windows：建议优先 **Windows App + 本机远程桌面 + Tailscale**（相对 Chrome 远程桌面：已有私网则不必再挂一套 Google 远控）。说明 Agent 客户端桥接与 Chrome 远程桌面无关。
- Mac 连过一次不会出现在 iPhone 列表；家庭自建 PC 常**不用**登微软账户，用「添加 PC」即可。
- 卡在 Initializing：本机 `TermService` / 3389 正常；Tailscale 上手机节点曾 **offline**。用户打开 Tailscale 后远控成功。
- 用户确认可继续；再核管理员通道已完成。随后 SSH 登录成功。

做成了：

- `GrokBot-Admin`（SYSTEM、按需）与 `C:\ProgramData\GrokBot` 作业目录 / `run-job.ps1` 就绪。
- iPhone 经 Tailscale + Windows App 远控成功；SSH 实测成功。
- Windows 已用激活码激活；ChatGPT / Grok Bot 开机启动项确认有效。

还剩：

- 桌面临时脚本（`finish-min` 等）可择机清理。
- 本机计算机名仍为长名（改名需重启；此前约定不擅自重启）。

## 所学

- Windows 远程代跑应拆成「命令行服务」与「提权任务运行器」两层；不能拿 Linux 的 Tailscale SSH 硬套。
- 能力包装挂死 ≠ 无网：要有**超时 / 备选安装路径**（winget），不能只等异常。
- 手机远控 Initializing：先查手机 Tailscale 是否在线，再查本机 RDP。
- 跨设备「已保存的 PC」对个人 RDP 往往不同步；不要假设 Mac 列表会到 iPhone。
- 管理员通道权限等同可触发 SYSTEM：落地后仍须聊天确认；22 对任意来源开放只适合过渡。

取舍补充：

- 激活：破解 / 假 KMS vs 正版密钥或组织 KMS——认合法路径；用户最终自备激活码。
- OpenSSH 安装：Windows 能力包 vs winget Preview——能力包优先但挂死后必须切 winget。
- 手机远控：Chrome 远程桌面 vs Windows App + Tailscale——已有 Tailscale 时认后者。
- Agent 控机：不依赖 Chrome 远程桌面。

## 行动指南

### 主题行动指南

#### 背景

一台常开的 Windows 需要「人不在键盘前也能运维」，且官方没有基于身份的 Tailscale SSH 服务端；另需偶尔用手机看屏。

#### 核心问题

如何在只当面（或远控能点）一次提权的前提下，得到可重复的：远程命令行、聊天确认后的管理员任务、以及手机私网远控。

#### 核心解决方案

1. 当面或远控下完成一次性管理员安装：OpenSSH 服务端 + 约定目录下的 SYSTEM 计划任务运行器。不做：假设聊天一句即可远程最高权限却从未建过通道。
2. 能力包装若长时间无进展：超时后改用包管理器安装 OpenSSH，不要只等能力包异常。不做：无限干等无进度条的能力包。
3. 日常管理员操作：把脚本放入 pending，聊天确认后触发约定任务。不做：无确认静默跑 SYSTEM 作业。
4. 手机看屏：私网组网在线后，用系统远程桌面客户端「添加 PC」连接；本机先开远程桌面。不做：指望另一台电脑上的主机列表自动同步到手机。
5. 收紧访问：优先仅经私网使用 SSH/RDP；长期改为密钥登录并收窄防火墙。不做：长期把 22/3389 对公网任意来源开放当常态。

#### 验收标准

- OpenSSH 服务在跑且开机自启；约定端口在听。
- 约定名称的 SYSTEM 计划任务存在，且能按需触发运行器。
- 从另一台已加入同一私网的设备 SSH 登录成功。
- 手机私网在线时，远程桌面客户端能进入桌面（不长期卡在 Initializing）。

### 细节与其他

#### 若再装管理员通道（本机约定）

则：

1. 目录：`C:\ProgramData\GrokBot\`（`scripts`、`jobs\pending|done|failed`、`logs`、`bin`）；运行器 `scripts\run-job.ps1`。
2. 任务名：`GrokBot-Admin`（SYSTEM、最高权限、按需）。
3. 触发：向 `jobs\pending\` 投放 `.ps1`，再 `schtasks /Run /TN GrokBot-Admin`（先聊天确认）。
4. 安装日志 / DONE：`C:\ProgramData\GrokBot\logs\admin-channel-install.txt` 与 `admin-channel-install.DONE`。
5. 能力包装挂死：停掉卡住的安装后，用 winget 安装 OpenSSH Preview（或等价包），再配置 `sshd` 自启并注册任务。可选项：只重试能力包——本次已证明会挂死，不优先。

#### 若用 iPhone Windows App 连本机

则：

1. 手机 Tailscale 须 Connected，节点在线。
2. App 内「添加 PC」，填 Tailscale 短名或私网地址；用户名用本机账户（可带 `计算机名\` 前缀）。
3. 密码用 Windows 登录密码；不要发到聊天。
4. 卡在 Initializing：先看手机 Tailscale 是否 offline，再查本机远程桌面服务与端口。可选项：Chrome 远程桌面——无私网时可用；已有 Tailscale 时不必再开一套。

#### 若 SSH 登录

则：从已加入同一 Tailscale 的机器 `ssh` 到该 Windows 短名或私网地址，用户名与本机账户一致。长期应改为密钥并收窄防火墙；当时未比较其它堡垒方案。

#### 若复查开机启动项「没起来」

则：先看用户启动文件夹快捷方式与当次登录后的进程启动时间，再查「启动应用」是否被禁用。本次 ChatGPT 实为已自启，窗口可能被遮挡。
