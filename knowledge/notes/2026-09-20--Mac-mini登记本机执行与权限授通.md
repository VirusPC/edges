【背景】
要把 Grok Bot 接到家里的 Mac mini 上本机执行：确认机器在线后打开「备忘录」并写入测试文案「grok bot测试连接」。目标是以后能在这台机器上代开 App、写内容，并尽量少被 macOS 权限弹窗打断。

【过程】
- 先确认 Mac mini 已在 mesh 上线，但当时还不能本机执行：未登记到 Grok Bot「电脑」列表，且远程 SSH 免密未通。
- 用户坐在 Mac mini 前，在 Grok Bot 里完成本机登记；登记后节点显示为 ChengdeMac-mini，连接正常。
- 通过本机执行打开「备忘录」并成功新建测试笔记；过程中出现自动化等权限弹窗，需用户点同意。
- 为减少反复弹窗：先开启「辅助功能」给 Grok Bot（否则无法代点系统设置里的开关）。
- 复查「自动化」：备忘录、System Events 已授权。
- 「完全磁盘访问」「屏幕录制」等敏感项：自动改写会被安全审核拦住，由用户在系统设置里手开。
- 最终复查：辅助功能、屏幕录制、完全磁盘访问、Apple Events（自动化）均已授权；再次写入「复查测试」笔记无新弹窗；本机 Desktop 可读。

【所学】
- 「mesh 在线」不等于「Grok Bot 能控桌面」：必须完成本机执行登记。
- macOS 权限不能静默永久跳过，但授一次会记住；反复弹窗通常是授权对象不对或未授「辅助功能」，导致后续自动化也无法代点。
- 代操作的顺序应是：先辅助功能 → 再自动化/其他；完全磁盘访问、屏幕录制属于高敏权限，宜用户确认后手开或走明确批准。
- 控备忘录一类 App，关键是自动化（Apple Events）指向「备忘录」等目标 App，而不是只开辅助功能。

【行动指南】
- 若要在新 Mac 上让 Grok Bot 本机执行：先在该机打开 Grok Bot → 设置里的「电脑 / 本机执行」完成本机登记 → 再试一次简单操作（如打开备忘录）。
- 若每次操作都弹权限窗：到「系统设置 → 隐私与安全性」，确认 Grok Bot 已打开辅助功能、自动化（备忘录 / System Events 等）、按需打开完全磁盘访问与屏幕录制；改完后重启一次 Grok Bot。
- 若只能远程 ping 通却无法开 App：检查是否已登记本机执行，不要假设 mesh 在线即可控桌面。
- 若 Grok Bot 大版本重装或换 bundle 后弹窗复发：重新核对上述权限列表，必要时重新添加 `/Applications/Grok Bot.app`。
