# 2026-09-26--家庭实验室断电恢复与有线局域网总览

> 由当晚多助手实操整理。公开库已脱敏：不含 Mesh 私网数字地址、授权链接、密码与 API token、各主机地址与网关 MAC。网段结构只留 `10.42.0.0/24`。完整含地址的台账在本地协作目录。

【背景】
用户常开的一台 Linux 小主机当晚突然失联，原话是问「是不是掉线了」，随即说明「电源断了下，刚重新开机」。由此展开：不间断电源选型、默认进 Linux、一键恢复脚本、全网远程壳免密、用交换机把四台机器收成同一有线局域网、NAS 共享在三端挂成磁盘、审计每台的 Mesh/隧道客户端、以及用手机/笔记本控 Windows 屏幕。用户后来说「今晚这些事情非常重要。各种细节都很重要。」要求按主题写成可复盘的详细笔记。

【过程】
1. **复电与默认系统**：确认是整机不在网而非只灰助手；指导固件菜单选 Linux、把盘内启动顺序改成 Linux 优先；写好运维恢复脚本并在远程壳打通后代跑；外网、共享盘、容器等项恢复为可用。讨论 UPS：要约半小时续航须看电池能量与 USB 通信自动关机，不能只看 VA 数字。脚本曾出现「已在网却被误判未入网」的假警报，当晚修好。  
2. **远程壳齐套**：在 Linux 小主机、NAS、云主机、台式 Mac 上打开基于身份的远程壳；Mac 必须卸掉沙盒图形客户端改用开源守护进程才能当「被连端」。NAS 曾误判在容器里，实际系统包已在跑，经有线从邻机登上去打开开关；遇 Permission denied **不盲重试**（防 UGOS 锁 IP）。删旧 Mesh 节点要用 Access token 而非 Auth key。Windows 新机不能当该远程壳服务端，改为系统 OpenSSH / 远程桌面路线，并新建专用设备助手；主机显示名缩短到好记的短名 `4070ts-win11`。  
3. **有线局域网定稿**：购买/使用傻瓜交换机连接四台（小主机、Mac mini、Windows、NAS）。用户明确「没有路由器，靠小主机」当网关与地址分配——形态记作 **家庭有线同网段 `10.42.0.0/24`、GTR 出网**。澄清 NAS 自有有线网卡、无 Wi‑Fi；Windows「没连 Wi‑Fi 也能上」是因为网线经交换机走到小主机出口。公开稿只留该网段，不写各主机地址与网关 MAC。  
4. **NAS 当磁盘**：Windows 映射多盘符，Mac 挂到用户目录下 NAS 文件夹，Linux 写进开机自动挂载。新建独立共享不会自动出现在客户端——补挂照片库共享后，约定以后少建独立共享，优先在已有数据共享下用英文子目录（docs/downloads/tmp/media）作为全家共通入口。Mac 有线未通时曾经 Mesh 挂载，属技术债。  
5. **客户端审计**：表格式核对 Mesh 与隧道客户端；给 Windows 补装隧道 CLI（尚未登录开隧）；修好 Mac 卸图形版后命令行指错路径（坏 stub）的问题。  
6. **屏幕远控**：Mac 对 Mac 继续屏幕共享；对 Windows 用官方 Windows App / 远程桌面，并在专业版上启用远程桌面；说明账号用系统密码而非 PIN。顺带关掉该 Windows 自动锁屏以免远控被打断。  
7. **支线**：企业 Wi‑Fi 按「保护的 EAP + 密码内层」（PEAP+MSCHAPv2）配置，且约定 NAS 不上企业无线；浏览器收藏夹同步未开导致翻不到 VPN 书签；1Password 仅共享库对助手可见且自动填有本机边界；Windows 更新报错 0x80248007 清理缓存；Wi‑Fi 驱动过旧导致办公 SSID 突然扫不到，已换较新正式驱动；机箱灯走厂商灯控面板（是否关灭未确认）；ChatGPT 与桌面助手加入开机启动。

【所学】
- **问题（总）**：常开小主机断电级失联；远程壳不齐；有线拓扑与网关未定稿；NAS 不能当三端磁盘用；Mesh/隧道家底不清；要看 Windows 屏幕却没有可用远控入口。
- **定稿方案（总）**：小主机默认 Linux + 恢复脚本 + 身份远程壳代跑；四台 Linux/NAS/Mac 开身份远程壳（Mac 非沙盒）；傻瓜交换机四机同网（只记网段 `10.42.0.0/24`）、无独立路由器、小主机当网关；三端 SMB + 少建共享、多用 `data/shared` 英文子目录；审计表补齐 Windows 隧道 CLI 与 Mac CLI；Windows App + 专业版远程桌面 + 本机账户密码控 Win 屏。支线规则：企业 Wi‑Fi 用保护的 EAP、NAS 不上企业网、设备助手按机拆分。
- 失联要先分「助手灰」还是「整机死」；复电能力 = 默认系统正确 + 恢复脚本 + 可远程代跑。
- 「网上」不等于「身份免密壳」；图形沙盒客户端可能故意不提供被连端。
- 拓扑上「存储核心」和「网关核心」不是同一个问题；有没有独立路由器必须先问清。
- 存储共享的产品化靠「子目录约定」，不靠「每新建一个共享就全网自动出盘符」。
- 人不在键盘前时，第一次提权仍要当面；之后才能用管理员任务/远程管理员会话。

【行动指南】
- 若小主机再断电：先确认进入 Linux → 跑恢复脚本或远程代跑 → 再查共享盘与容器。  
- 若新 Linux/NAS 入网：打开身份远程壳并用另一台已通节点实测登录。  
- 若 Mac 要当被连端：确认不是沙盒图形版。  
- 若再有文件要全家共用：优先放进数据共享下的 shared 子目录；只有权限/备份策略要求时才新建独立共享并三端补挂。  
- 若 Mac 控 Windows 屏幕：走 Windows App + 已启用的远程桌面 + 系统密码。  
- 若进公开知识库：先去掉 Mesh 数字地址、密钥、授权链接、各主机地址与网关 MAC；网段结构可留 `10.42.0.0/24`。
