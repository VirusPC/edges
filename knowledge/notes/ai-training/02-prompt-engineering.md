# 模块 2: 提示词工程 (Prompt Engineering)

> Prompt 设计、优化技巧、模式、Few-shot、Chain-of-Thought

---

## 本模块捕获内容

- **[技巧]** Zero-shot, Few-shot, Chain-of-Thought, Self-consistency
- **[模式]** 角色扮演、结构化输出、思维链、ReAct style
- **[优化]** Prompt 迭代、A/B测试、长度优化
- **[框架]** DSPy, LangChain Prompts, Guidance
- **[反模式]** 常见的 Prompt 错误和避免方法

## 快速记录模板

### Prompt 技巧
```markdown
- **[技巧]** {技巧名称}
  - 使用场景: {什么时候有效}
  - 模板: {具体的 prompt 写法}
  - 示例: {输入 → 输出}
  - 效果: {提升多少}
```

### Prompt 模式
```markdown
- **[模式]** {模式名称}
  - 结构: {prompt 的组成部分}
  - 变量: {可以替换的部分}
  - 示例完整 prompt: {实际案例}
  - 适用模型: {哪些模型表现好}
```

### Prompt 优化
```markdown
- **[优化]** {优化方法}
  - 问题: {原 prompt 的不足}
  - 改进: {如何修改}
  - 迭代过程: {改了哪几次}
  - 最终结果: {前后对比}
```

### 工具/框架
```markdown
- **[工具]** {工具名称}
  - 功能: {解决什么问题}
  - 使用方式: {代码/命令示例}
  - 对比: {vs 手写 prompt}
  - 局限: {不适用场景}
```

### 踩坑记录
```markdown
- **[踩坑]** {问题描述}
  - 现象: {模型表现如何}
  - 原因: {为什么会出现}
  - 解决: {如何修复 prompt}
  - 教训: {下次如何避免}
```
