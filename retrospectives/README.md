# 复盘

阶段性回看。周复盘覆盖过去一周，日复盘覆盖过去一天。一篇复盘记下这段时间的范围和事实、对照目标之后的判断，以及当时对笔记、任务、项目记忆候选的处理。

## 边界

复盘记录回看。笔记、任务、项目记忆和 Edge 记录各自的产物。

| 要留下的东西 | 写入 | 复盘里保留 |
| --- | --- | --- |
| 值得再读的澄清或材料 | [`notes/`](../notes/README.md)，命令 `edges notes` | 候选一句话，以及写入后的路径 |
| 下一步要做完的事 | 领域 [`tasks/`](../tasks/README.md) 或维护 [`.harness/tasks/`](../.harness/tasks/README.md)，命令 `edges tasks` | 候选一句话，以及开卡后的路径 |
| 以后还要遵守的结论 | 所属作用域的 `.harness/memory/`，命令 `edges memory remember` | 候选一句话，以及入口路径 |
| 可复用的判断 | 先记成笔记，再按 [`edges/README.md`](../edges/README.md) 提炼成 Edge | 洞见留在复盘；Edge 另写一篇 |
| 这次回看本身 | [`weekly/`](weekly/README.md) 或 [`daily/`](daily/README.md) | 全文 |

单次对话整理成笔记时用四栏结构（背景、过程、所学、行动指南），术语见 [`CONTEXT.md`](../CONTEXT.md) 的「复盘四栏」。周复盘和日复盘按本目录的章节成篇。

## 约定

- 周复盘的命名、章节和登记见 [`weekly/README.md`](weekly/README.md)。
- 日复盘的命名、章节和登记见 [`daily/README.md`](daily/README.md)。
- 一篇内容是一个目录，正文入口是 `INDEX.md`。附件与入口放在同一目录。
- 本仓公开。复盘遵守根 [`README.md`](../README.md) 的「隐私与脱敏」。
- 发现路径：根 README 的本层内容登记本目录，本目录再登记周复盘与日复盘。写入就是编辑 `INDEX.md`，并在对应清单的「本层内容」补一行。
