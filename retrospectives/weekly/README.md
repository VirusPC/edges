# 周复盘

命名：`retrospectives/weekly/<周一日期>--周复盘/INDEX.md`（周一到周日，日期取该周周一；例 `retrospectives/weekly/2026-10-05--周复盘/INDEX.md`）。同一周一只保留一篇，补记改原来的 `INDEX.md`。

## 正文

`INDEX.md` 以 `# <YYYY-MM-DD> 周复盘` 起。六节顺序固定。

### 范围

一两行：时间窗，以及看了哪些来源（仓库、各助手对话）。

### 本该怎样

本周事先的目标，加上上期周复盘「下次做什么」里的行动。没有就写明没有，不事后画靶。

### 实际怎样

可核对的事实，带链接。上期行动逐条标：做成、没做成，或卡住（写原因）。

### 为什么

差距的原因，用「可能因为…」口吻。至少一条做得好、该保持的。

### 下次做什么

至多 3 条。每条写清怎么算完成。

### 建议补充内容清单

该进 Harness 但没进的 Memory / Skill / Note / Task / `AGENTS.md` 硬约束候选。每条一句话，加上建议去处，以及处理结果：已写入路径、不做原因，或留待触发条件。没有就写明没有。

## 登记

在本文件「本层内容」追加一行，描述用 ` — `（两侧各一空格）分隔：

```markdown
- [2026-10-05 周复盘](2026-10-05--周复盘/INDEX.md) — 一句话范围
```

日期换成该周周一。这一行只说明格式，仓库里不放对应正文。
