# 归档 (Archive)

此目录类似整个知识空间的回收站：过时、重复、错误或低活跃度的内容退出活跃区域，以降低持有成本，但仍保留来源和恢复的可能。它是退出机制，不是知识出口，也不限于失效的 Edge。

## 怎么归档

归档保留内容从仓库根起的原始相对路径：

```text
notes/a/ → archive/notes/a/
projects/foo/report/ → archive/projects/foo/report/
```

曾经有意义或被引用过的内容应归档，并写明原因；误建、空白或纯临时文件可以直接删除。被继任 Edge 替代的旧 Edge 归档到对应的 `archive/edges/` 路径。

## 附件

图片、音频等附件与所属内容的入口文档放在同一个目录。多个内容单元需要同一附件时，各自保存副本，保持目录可以独立迁移；不再集中放入根层 `resources/`。找不到引用的旧 `img/` 附件归档到 `archive/img/`，保留原仓库相对路径，不凭文件名猜测归属。
