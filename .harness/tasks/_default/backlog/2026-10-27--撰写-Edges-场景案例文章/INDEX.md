**背景：**
用户希望在推广准备中补充面向使用场景的文章，让外部读者理解 Edges 与自身工作的关系。实验为效果表述提供证据，Skills 与接入验证提供可照做的使用路径，场景素材承担真实过程。具体文章题目与数量由选题子任务确定。

本卡随推广主任务归入 Edges 框架仓。文章产物另按目标内容仓的规则起草和归档；个人公开脑的 posts/ 由用户维护，AI 草稿在该目录之外起草。文章经用户审阅，本卡不预设发布渠道，也不自动对外发布。

- 主任务：[Edges 对外推广准备：实验、Skills 与场景案例](<../2026-10-27--Edges-对外推广准备实验Skills-与场景案例/INDEX.md>)
- 依赖或需要引用的成果：[确定 Edges 使用场景与案例素材](<../2026-10-27--确定-Edges-使用场景与案例素材/INDEX.md>)；[完成 Edges 核心价值实验并整理结果报告](<../../../evaluation/backlog/2026-10-27--完成-Edges-核心价值实验并整理结果报告/INDEX.md>)；[验证 Edges 新用户接入与首次使用](<../../../agent-clients-ux/backlog/2026-10-27--验证-Edges-新用户接入与首次使用/INDEX.md>)

**目标：**
把确认的场景写成有真实过程、结果依据和接入步骤的案例文章草稿，供用户审阅。

**动作：**
- 围绕具体困扰展开叙事，写清使用过程、产物、效果与代价。
- 引用实际实验或使用记录，并写明结论的适用条件。
- 附上经验证的接入步骤与相关 Skill 入口，完成文章审阅和修订。

**完成标准：**
- [ ] 确认的选题均有可审阅的完整草稿，包含场景、过程、结果和复现入口。
- [ ] 效果数字与案例事实有出处，接入步骤与验证结果一致。
- [ ] 文章经用户审阅并完成所要求的修订；正式发布状态与草稿完成状态分别记录。
