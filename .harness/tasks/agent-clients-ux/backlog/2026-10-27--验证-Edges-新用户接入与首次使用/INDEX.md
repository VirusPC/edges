**背景：**
2026-10-27 推广讨论中，用户把 Skills 梳理的目的明确为方便大家接入。仅完成 Skill 文件调整或 CLI 写入读回，还不足以说明外部 Agent 能顺利开始使用。本任务验证面向新用户的完整接入路径，并为案例文章提供可照做的步骤。

已有“edges skills 与 Agent 回归评测”任务关注长期行为回归，本任务聚焦本次推广采用的宿主与场景，从新环境到首次使用的过程；覆盖范围在执行前确定。

- 主任务：[Edges 对外推广准备：实验、Skills 与场景案例](<https://github.com/VirusPC/edges-brain-viruspc/blob/main/.harness/tasks/site-and-content/backlog/2026-10-27--Edges-%E5%AF%B9%E5%A4%96%E6%8E%A8%E5%B9%BF%E5%87%86%E5%A4%87%E5%AE%9E%E9%AA%8CSkills-%E4%B8%8E%E5%9C%BA%E6%99%AF%E6%A1%88%E4%BE%8B/INDEX.md>)
- 依赖或需要引用的成果：[edges 按模块拆 skill（一模块一个）](<../../../edges-extensions/backlog/2026-10-25--edges-按模块拆-skill一模块一个/INDEX.md>)；[确定 Edges 使用场景与案例素材](<https://github.com/VirusPC/edges-brain-viruspc/blob/main/.harness/tasks/site-and-content/backlog/2026-10-27--%E7%A1%AE%E5%AE%9A-Edges-%E4%BD%BF%E7%94%A8%E5%9C%BA%E6%99%AF%E4%B8%8E%E6%A1%88%E4%BE%8B%E7%B4%A0%E6%9D%90/INDEX.md>)

**目标：**
确认目标用户能沿公开入口完成接入、让 Agent 找到正确 Skill，并完成选定的首次真实任务。

**动作：**
- 从选定的外部用户环境执行接入流程，记录所需条件与人工介入。
- 用普通需求验证 Skill 发现和任务执行；在相关场景中验证新会话能继续读取此前材料。
- 修正或明确接入卡点，并把验证过的步骤交给案例文章使用。

**完成标准：**
- [ ] 确认范围内的接入、Skill 发现与首次任务已完成实际验证，结果和卡点有记录。
- [ ] 文章使用的接入步骤能对应到验证结果；未覆盖或仍有限制的环境已说明。
