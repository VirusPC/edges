知识闭环的反馈端必须回到捕获，而不是直接回到知识生产或沉淀。

**Why:** 用户在 2026-09-09 纠正 README 图示：行动结果、外部反馈和新证据首先是新的输入，必须再次被捕获和判断；若直接指向 Notes、专项或沉淀阶段，就隐含跳过了输入识别过程。“演化”是反馈重新经历捕获、提炼和更新后产生的结果，不应成为绕过捕获的捷径。

**How to apply:** 绘制或描述 Edges 的知识闭环时，使用「捕获 → 生产 → 沉淀 → 使用 → 反馈 → 回到捕获」。可以说明反馈推动知识与系统演化，但回环箭头必须指向捕获；外部反馈是否进入 Note、专项或 Edge，应在捕获后再判断。
