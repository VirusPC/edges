解释或改 AGENTS.md 层标记时：系统入口 `AGENTS.md` 带 `project-harness-*` 组成登记是递归系统二的基础假设（见 `project_recursive_system_two_entry`）。`.harness/tasks/<project>/AGENTS.md` 是否应作为系统入口，取决于 grill 待答 Q10——若仅「有独立维护职责的作用域」才配真实系统入口，则 Task Project 不应继续用系统入口文件承载任务清单；若组织目录都配系统入口，则其上的 project-harness-local 列出任务是合法的系统二组成。

**Why:** 用户 2026-10-06 先指出 Task Project 上的标签像语义泄漏，随后 grill 确立「AGENTS.md = 系统入口且必须带组成」。旧结论「凡 Task Project 上的 project-harness 都是泄漏」不再无条件成立，需等 Q10。

**How to apply:** 在 Q10 答出前，不要批量删除 Task Project 的 AGENTS.md 或剥标记。答 B 则迁移 Task Project / 类型索引离系统入口；答 A 则保留并更新术语说明。类型入口是否用 AGENTS.md 同样挂 Q10。
