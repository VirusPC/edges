# Mission: CrewAI

## Why
Build a clear mental model of CrewAI's core concepts (Agent, Task, Crew, Flow, and how they compose) so the learner can read CrewAI code and docs fluently and judge it against other agent stacks, before writing any code.

## Success looks like
- Explain, without notes, what an Agent, Task, Crew, Process, and Flow are and how they relate
- Read an official CrewAI example (crew.jsonc / Flow main.py) and narrate what runs, in what order, with what data passing
- Say when to reach for a Crew vs a Flow

## Constraints
- Concepts first; no coding required for now
- Chinese-first explanations; keep official English terms

## Out of scope
- Writing or deploying CrewAI projects (for now)
- CrewAI Enterprise / AMP platform features
