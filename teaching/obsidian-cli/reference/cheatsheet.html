Obsidian CLI 命令速查表

前提：Obsidian 桌面应用正在运行。命令 obsidian help 永远是最新的权威列表。

语法三规则

  • 参数用 = 赋值，含空格要引号：obsidian create name="My Note"
  • 标志是布尔开关，无值：silent overwrite
  • 多行内容用 \n（换行）和 \t（Tab）

定位

写法含义
file="名字"像 wikilink 一样按名解析，无需路径/扩展名
path="folder/note.md"vault 根起的精确路径
vault="名称"（放最前）多 vault 时指定目标；缺省用最近聚焦的 vault
都不给作用于当前活动文件

常用命令

obsidian read file="My Note"                 # 读笔记
obsidian create name="New" content="# Hi" silent   # 建（可加 template=）
obsidian append file="My Note" content="…"  # 追加
obsidian search query="关键词" limit=10      # 搜索
obsidian daily:read / daily:append content="- [ ] 任务"  # 每日笔记
obsidian property:set name=status value=done file="My Note"  # 改属性
obsidian tasks daily todo                   # 任务列表
obsidian tags sort=count counts             # 标签统计
obsidian backlinks file="My Note"           # 反向链接

通用修饰

  • --copy：任何命令的输出复制到剪贴板
  • silent：不打开/切换文件窗口（Agent 批量操作必备）
  • total：列表命令返回计数
  • 完整命令树：obsidian help（含 dev:* / plugin:* 开发者命令族，本 mission 暂不涉及）
