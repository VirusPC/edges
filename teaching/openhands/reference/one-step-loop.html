一次用户请求：V1 的 8 步

从 Conversation 进门，穿过无状态的 Agent.step，到 Workspace 里跑工具——一页记牢。

  1. User → Conversation send_message(...) 再 run()；Conversation 拥有生命周期与 ConversationState。
  2. Message → Event 追加进只读向前的 EventLog（如用户 MessageEvent）；事件既是记忆也是集成总线。
  3. Conversation 编排 Agent.step() Agent 无状态：从 state 读历史，往 EventLog 写新事件。
  4. 可选 Condensation Condenser 可能压缩历史 / 发出 Condensation，再交给 LLM。
  5. LLM 查询 可转换事件 → messages；模型返回 tool calls 或纯文本。
  6. 解析 → ActionEvent(s) 或 MessageEvent 工具调用变成类型化 ActionEvent；纯文本可能结束本步。
  7. 安全 / 确认门 分析器 + 策略可能设 WAITING_FOR_CONFIRMATION 并返回。
  8. 在 Workspace 执行工具 → ObservationEvent(s) Action→Observation；本地进程或远程 Agent Server 取决于 workspace。循环直到完成 / 暂停 / 出错。
V0 词汇桥（可选）：FE ↔ Backend ↔ EventStream ↔ Runtime ↔ ActionExecutionServer。 教 V1 时优先用 Conversation / EventLog / Agent / Workspace / Agent Server。
