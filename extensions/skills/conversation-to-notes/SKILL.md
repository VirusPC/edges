# conversation_to_notes

将原始对话记录整理为结构清晰的中文笔记摘要。
生成符合格式 YYYY-MM-DD--主题简述.md 的标题。
遵循 **Facts - Insights - Actions** 逻辑组织核心内容。

## When to Use:
当需要将原始对话或聊天记录总结转化为可阅读笔记时使用。

## Inputs:
- 原始对话全文

## Instructions:
1. 识别对话的核心讨论主题。
2. 生成标题，格式严格为：YYYY-MM-DD--主题简述.md
3. **讨论主题**：简洁描述本次对话的背景和核心议题。
4. **Facts (主要结论)**：提取对话中达成的共识、定论或发现的关键事实。
5. **Insights (认知更新)**：识别对话中产生的关键洞察、逻辑转变或可复用的 Edge（判断优势）。
6. **Actions (行动指南)**：列出明确的具体决策、后续行动项或实验计划。保留可直接实施的具体细节。
7. **补充说明**：记录不属于上述分类但重要的琐碎信息、背景补充或相关参考。
8. 所有输出必须为中文。

## Output Format:

文件名：
YYYY-MM-DD--主题简述.md

---

【讨论主题】
...

【主要结论】
(事实与共识)
...

【认知更新】
(洞察与 Edge 雏形)
...

【行动指南】
(决策与后续动作)
...

【补充说明】
(其他重要细节或备注)
...

## Constraints:
- 不添加原记录中不存在的新观点。
- 标题必须严格符合 YYYY-MM-DD--主题简述.md 格式。
- **结构完整**：确保包含所有定义的章节，若某项确实无内容可写“无”。
- 输出必须为中文。

## Limitations:
- 依赖输入文本提供足够语境。
