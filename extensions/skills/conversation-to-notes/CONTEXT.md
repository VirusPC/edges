# CONTEXT — conversation-to-notes

## Glossary

- **复盘笔记**：由一场（或多场）对话整理出的、可独立阅读的中文笔记，默认入库 `VirusPC/edges` 的 `knowledge/notes/`。
- **主题行动指南**：行动指南中的主题层。包含：背景、核心问题、核心解决方案（可执行步骤）、验收标准。只写角色与机制，不绑具体主机名、网段、脚本路径。
- **细节与其他**：行动指南中的细则层。每条一个 Markdown 小标题，形如「若…」；正文写「则…」；复杂步骤用列表。主机名、路径、网段、账号等操作细节只出现在这一层。
- **验收标准**：主题行动指南的最后一节。当作以后「当真把这件事当任务执行」时的完成判定清单（可勾选），不是散文式愿望。
- **过程时间线**：过程章节按时间推进；小节标题带具体时刻或时间段；少评价。
- **白话**：完整中文句；禁止自创黑话、口头禅式小标题、未经解释的自创缩写。真实产品/协议名可保留。

- **行动类对话**：讨论本身以「要做成某事」为主；整理时内容优先进入行动指南，所学从简。
- **学习类对话**：讨论以理解知识点为主；所学写知识点总结，行动指南单独写「如何用」。
- **总览笔记**：同日或多主题的一篇主线笔记，链到各主题 note；补充说明可引用其它 note。
