# ADR 0008: 取舍补充且不压缩过程；做法须带可选项

## Status
Accepted

## Context
过程里常有真实 tradeoff。若在所学/行动指南「收成」取舍，容易把过程压短、丢掉记录价值。用户要求凡写「做什么」都要带相关可选项与不做原因。

## Decision
1. 过程中的真实取舍原样保留，禁止用所学/行动指南去压缩或替换过程内容。
2. 所学与行动指南**补充**取舍：相关可选项、为什么不做、最终认的知识与方案。
3. 凡写「做什么 / 怎么做」（主题解决方案与细节若则），必须同时写相关可选项与不做原因；只写对话出现过或显然相关的；未比较则写明「当时未比较其它方案」，不编造。

## Consequences
笔记可能更长；以完整为先。细节层与主题层都要带弃因，不能只给唯一步骤。
