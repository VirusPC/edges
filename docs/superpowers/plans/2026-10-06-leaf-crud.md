# 叶子真执行 CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Memory、Note、Skill 里还没有的 list / get / delete 真的读写节点；`edges note` 的入库改为 `edges note create`。

**Architecture:** 写入仍走现有 `rememberMemory` 和 `runIngest`。新的 list / get / delete 通过 `NodeService` 加载对应叶子，不在命令里拼文件路径。已落地的 create / update 提示命令保持不变，不另写一套写入。

**Tech Stack:** Node 22、现有 `NodeService`、`Task` 以外的 `MemoryNode` / `NoteNode` / `SkillNode`。

**Spec:** ADR 0027。Q20 的真执行表。

## Global Constraints

- `memory create` / `update` 和 `skill create` / `update` 继续只提示，退出码 2。
- `edges note` 不带 `create` 时是用法错误，退出码 2，并提示使用 `edges note create`。
- 成功 JSON 是 `{ status: "success", ... }`，失败是 `{ status: "failed", errorCode, reason }`。
- get / delete：Memory 用 `--type` 加 slug；Note 用入口路径；Skill 用 `SKILL.md` 路径或 name。

## Tasks

### Task 1: `note create`

把现在的 `edges note` 动作挪到 `note create`。裸 `edges note` 返回 `VALIDATION_ERROR`。更新 note 帮助和调用测试。

### Task 2: Memory list / get / delete

`listMemory`、`getMemory`、`deleteMemory` 放在 `services/memory/`。delete 删的是该 type 下这个 slug 的条目目录，不删类型入口。命令只解析参数并映射结果。

### Task 3: Note list / get / update / delete

list / get / delete 按 Note 入口路径。update 改标题或正文，不改入库时的 git 流程。

### Task 4: Skill list / get / delete

按 `SKILL.md` 查找。delete 删除该技能目录。create / update 仍指向 `edges memory remember`。
