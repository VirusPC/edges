# 对话整理采用复盘四栏

整理对话为 Note 时，Facts–Insights–Actions（及其中文「主要结论 / 认知更新 / 行动指南」映射）容易把过程与判断塌成一栏、把行动写成待办清单。我们改用**复盘四栏**（背景→过程→所学→行动指南）：灵感来自 After Action Review，但不是美军官方 AAR 模板。四栏分开「为何谈 / 发生了什么 / 可带走的判断 / 带触发的做法」，并刻意不把「升 Edge」写进 conversation-to-notes（Notes → Edges 仍是另一步）。旧笔记不批量改写。

## Considered Options

- FIA 中文换皮（主要结论→事实、认知更新→洞察、行动指南→行动）：仍是三分法，栏会继续塌缩；已关闭的 PR / `skill/conversation-to-notes@1.1.0` 不要当已落地。
- ORID 精简：多一栏「感受」，对话整理不需要。
- 纪要三栏：仍缺「所学」与「过程」的硬分离。
- 无 AAR 谱系说明的 Background / Process / Learnings / Next Steps：结构相近，但读者容易当成通用会议纪要，也容易把 Next Steps 写成裸 todo。
