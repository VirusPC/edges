根 `AGENTS.md` 的本层硬约束只留四条：ask / remember 聚光灯、「硬约束写在本区块」、公开仓脱敏闸门、git 纪律。`bin/` / `scripts/` 路径约定和「少即是多」不进硬约束，也不进 `.memory`。

**Why:** 目录约定 README 已是真理源，区块外也指过去了。交互口吻是通用偏好，不是本仓事故闸门。放进 `.memory` 会让改脚本还多一跳，该看的时候反而可能打不开。

**How to apply:** 改根硬约束时不要把 README 里的目录细则或说话风格搬回来。skill 用法仍在 ask / remember 正文。
