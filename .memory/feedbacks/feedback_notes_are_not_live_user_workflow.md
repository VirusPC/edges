知识库或项目记忆里的工作流笔记，只能说「某日笔记/约定里写过」，不能说成「你的工作流」。那是落盘观察或当时约定，不是对用户当前怎么干活的知情。

**Why:**

2026-09-10 Slack 里用户追问「你知道我的工作流？」。上一句把 2026-09-05《Grok Bot 与 Cursor 联动互补》里的分工直接说成「你这边的工作流」，把推断说成知情。用户要的是这层区分，不是再背一遍笔记。

**How to apply:**

- 引用工作流笔记时标明来源和时间，用「笔记里写过」，不要用「你这边的工作流是」。
- 用户没有当场确认过的日常习惯，不要用「你这边」口吻讲成现状。
- `idea→todo→专家→Cloud` 这类项目记忆同样是约定，不是现场观察；需要时单独标明是记忆里的约定。
