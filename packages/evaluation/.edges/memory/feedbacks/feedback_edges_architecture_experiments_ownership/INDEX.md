验证 Edges 自身分层架构价值的实验，应将设计、数据、生成与评测程序、审计和报告作为完整实验归入框架评测体系；不能只迁程序与汇总，也不能因为沿用个人脑的框架选型工具就沿用个人研究归属。

**Why:** 用户在 2026-11-09 纠正 Harbor 三组记忆消融实验的归属，并明确要求「实验设计 数据集 eval程序 报告 等一切都放进去」。框架选型研究关注工具之间的比较，而此次实验关注 Edges scoped、root、none 的差异；共享工具和真实使用数据不改变研究对象，也不改变维护责任。实验只有程序和摘要时，数据依据、方法与运行证据仍然分散，无法从一个入口完整复查。

**How to apply:** 新实验先判断要验证的是 Edges 自身能力还是个人工具选型，再选择维护位置。框架实验统一组织方法、数据集及形成依据、运行和评分代码、完整结果与审计；旧个人研究入口只保留导航。可公开材料进 Git，含真实问题、来源标识和原始日志的完整材料在同一实验的忽略区归档，并保留受限备份；本地集中不等于远程备份。合成实验明确标识来源，连同生成逻辑、种子、真值依据、验证代码和数据报告一并维护，不能只留下生成后的题集，也不能冒充真实来源。归属迁移保留冻结运行来源；新实验另立协议和输出，不改写旧结果。
