验证 Edges 自身分层架构价值的实验，应按研究问题归入框架评测体系；不能因为沿用个人脑里的框架选型程序，就把新实验继续归入个人研究项目。

**Why:** 用户在 2026-11-09 纠正 Harbor 三组记忆消融实验的归属。框架选型研究关注工具之间的比较，而此次实验关注 Edges scoped、root、none 的差异；共享工具和真实使用数据不改变研究对象，也不改变维护责任。

**How to apply:** 新实验先判断要验证的是 Edges 自身能力还是个人工具选型，再选择维护位置。验证 Edges 的程序、协议说明与可公开的聚合结果由框架评测体系维护；旧个人研究入口只保留导航。含真实问题、来源标识和原始运行日志的材料维持非公开边界。归属迁移保留冻结运行来源，不把移动代码当作重新实验。
