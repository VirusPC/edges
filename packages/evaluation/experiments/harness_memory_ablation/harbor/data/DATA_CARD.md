# Harbor 真实记忆消融数据卡：公开视图

本卡描述已经冻结并执行的真实数据组成与建设方法。它依据原始数据卡、冻结协议和已完成审计整理，未新造题目、参考答案或 gold；不是原冻结文件的字节副本。原始数据卡在正式结果被读取前完成。完整原件统一归入本实验 [local/archive/](../local/archive/)，由 Git 忽略；公开克隆不随附。

机器可读的[构成聚合](dataset-summary.json)不含逐题记录，不能直接输入 runner。方法与隔离见[设计](../design/DESIGN.md)，准则见[标注审阅](../design/ANNOTATION_GUIDE.md)，结果见[公开聚合报告](../../../../reports/2026-11-09-harbor-memory-ablation.md)。

Gold 保留所有直接相关记忆，允许多份证据，不为提高 recall 而裁到五条。每题上限为 `min(5, gold_count)/gold_count`；最多 13 条 gold 的题上限为 38.46%。无 gold 题在非空可见库中没有直接相关记忆，recall、precision@5 和 MRR 为 N/A，另计误选，不按零分混入召回均值。

问答回答历史问题；执行前检索不执行原始任务，只选择应读记忆并解释适用规则。正式问答仅有 4 道正例适用 recall；执行前检索全是正例，无法估计该 track 面对不相关任务的误选率。

Scope 从用户明确目标、此前人类上下文或可核对元数据确定，不从 gold 目录倒推。共同根同时包含已知全局根、未知目录和无法映射的外部仓库；25 道共同根测试题不能全部称为“缺少来源”，明确 unknown 为 22 道。已知非根测试题只有 6 道，限制对深层就近发现的解释。

## 历史语料和时间过滤

记忆库含框架已登记 Memory 160 份、公开个人脑已登记 Memory 21 份，合计 181 份、7 个作用域。它不包含全部公开笔记、任务、技能正文、完整业务代码或全部私密知识。问题来自真实历史会话，不代表可检索库覆盖这些会话涉及的全部知识。

取 2026-10-31T00:00:00Z 前的 Git 快照，按已登记 Memory 叶子规则提取正文，分离 frontmatter；保留源信息、原始路径、历史版本和完整性信息于非公开原件。每条文件的可用时间来自冻结 revision 中该路径最近 Git commit，而非 frontmatter。逐题严格开放 `available_at < query_at` 的正文；跨作用域保留所有时间合格文件，scoped/root 正文相同，none 不放实验 memory / index。

这不是完整历史回放：若选中的固定版本晚于问题，不自动回找更早版本；截点后新建或修改的知识不进入。Git commit 时间不是人首次知晓或实际可读取的时间。部分上游时间只有分钟精度。所有保留题均有非空时间合格库。

## 标注、审阅与划分

初标、独立复核和统一裁决均由 AI agents 完成，独立审阅者不同于初标者，不是人类金标小组。保留来源类别、相关性理由、参考答案、拒收原因、审阅意见和完整性绑定；历史助手答案不能单独作为真值。具体规则见[准则](../design/ANNOTATION_GUIDE.md)。

只做最小指代恢复，5 题补充必要限定，12 题有核验过的更早上下文；不补答案，不将现场状态问题改写为抽象设计问题。19 条拒收包含历史证据不足、晚于问题的相关版本、含糊请求、机器派发和相邻重复主题。直接用户请求本身不保证适合检索实验。

以来源 session 的 SHA-256 前八个十六进制字符转整数后模五划分：余零为 dev，其余为 test，同来源不跨 split。源身份及实际摘要不公开；规则可公开。这不是按日期划分的未来预测留出集。不同来源仍可能有相同主题或 gold，按来源聚类不能消除全部主题相关性。

## 使用范围和已知局限

正式矩阵使用 31 题、三条件、每条件三次重复，固定 12 路并发，全部 279 次完成且零失败。单用户、单模型别名、目的性样本、AI 标注共享偏差和保守历史库限制泛化；只在重建记忆工作区运行，不能解释为完整原始任务成功率。

12 路时延可能受共享资源竞争与调度影响，提供方缓存未隔离。提示词的联网约束不等于网络硬隔离。工具终审发现 2 次读取运行时自带辅助 Skill，它不属于实验 Memory，不计入命中；none 指没有实验记忆，而非完全空的本地运行时。

整体 recall、token 和速度没有明确的分层优势证据；6 题已知非根作用域只有探索性信号，不能由此倒改样本或推广为普遍胜出。无记忆组 recall=0 是结构性基线；正文暴露不证明理解或因果使用，局部正则规则不是完整回答正确率。
