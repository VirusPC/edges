# 数据与完整原件

本目录保存此次真实记忆消融的数据说明和公开聚合构成；不是另造的公开替代数据集。

- [DATA_CARD.md](DATA_CARD.md)：真实来源、筛选、标注、时间与 scope 边界、数据划分及局限。
- [dataset-summary.json](dataset-summary.json)：与原始数据卡一致的规模、split、gold 和语料聚合；不含题目、答案或逐条标识，不能直接作为 runner 输入。
- [实验设计](../design/DESIGN.md)、[冻结协议公开视图](../design/protocol-v1.json)和[标注审阅准则](../design/ANNOTATION_GUIDE.md)：说明这批数据怎样形成、如何用于正式实验。
- [local/archive/](../local/archive/)：同一实验目录内的完整非公开原件落点，由 Git 忽略；归档就绪后在本机访问，公开克隆不随附。

完整归档包括原始分页、历史记忆库、候选、初标、独审与裁决、冻结 dataset、原始协议、实际运行源码、任务 / verifier、原生日志、完整统计和审计。实验根目录的[维护及复现入口](../README.md)负责归档与执行；通用程序不搬入 data/。本目录只描述既有真实数据，没有创建或替换任何问题与 gold。

原始输入、逐次输出与来源身份不得提交公开 Git。精确复现需要授权完整原件及冻结运行环境；公开聚合可核对配置与统计，不能恢复原始问题矩阵。授权输入的后续运行仍须使用新输出目录并与冻结结果区分。
