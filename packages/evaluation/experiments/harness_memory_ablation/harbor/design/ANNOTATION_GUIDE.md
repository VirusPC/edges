# 真实数据的标注与独立审阅准则

这是本次冻结数据建设方法的公开说明，不包含真实题目、参考答案、gold 标识或逐条裁决。完整标注、独审、拒收原因和封板材料归入 [local/archive/](../local/archive/)；数据组成见[数据卡](../data/DATA_CARD.md)，实验口径见[设计](DESIGN.md)。本文不新造题，也不追溯修改正式输入。

## 来源和候选资格

先从有界导出的根观测建立确定性候选，保留原始行、来源及时间。在已支持的用户轮次名称中，仍须识别实际发起者：输入槽和观测名称不自动证明是直接人类请求。按直接用户、Agent 派发、无法确定三类审查来源；正式保留集全部为直接用户请求，派发和来源不清的材料不能静默混入。

排除缺失输入输出、超出长度范围、已识别机器包装、同来源内重复提示和同一观测多版本的全部记录。重复版本不任选一份；原件仍保留。候选自动筛选不代替语义审阅。1,724 个候选中仅目的性选取 61 条进入逐条 AI 标注，不把其余候选称为已全文审完、全部不合格或无关。

## 题意、上下文与任务类型

保留原始用户意图。只允许最小指代恢复：用同 session 更早的人类消息或可核对元数据补齐必要的平台、设备、项目或路径限定，并保留原文和变更说明；不补答案、不改成更容易由语料回答的问题。无法可靠恢复的片段拒收。正式数据中有 5 题做此类最小规范化，12 题有经核验的更早上下文。

`memory_qa` 必须能回答历史时点的实际问题，不能把“当时实现或读过没有”改写成设计常识。`pre_task_retrieval` 保留真实工作请求，但只评执行前应读的记忆、适用规则与未知条件，不执行原始工作，也不将检索判为工作已完成。

历史助手答案只可辅助追查来源或形成待核实线索，不能单独证明正确答案、用户意图、来源类别或作用域。当前代码与今天的状态同样不能冒充历史时点证据。

## 时间、作用域与 gold

每题先固定可见库：只开放选定历史版本的 Git 可用时间严格早于问题的记忆。没有任何时间合格记忆的题，不进入正式 placement 或误选对照。Gold 必须来自该可见库，不得使用未来知识。

作用域取自用户明确目标、同 session 更早人类消息或可核对来源元数据，不从 gold 目录反推。不明确的当前目录保持 unknown；全局根、未知目录及无法映射的外部仓库可在运行中归共同根，但须保留证据分类，不能声称全部缺少来源。

逐条阅读正文并记录相关性理由：只有直接支持问题或具体行动规则的记录进入 gold。多份正文直接支持同一问题时保留全部，不只挑主证据，也不为 recall@5 裁到五条。泛化的入口导航并不自动成为任何任务的 gold；具体 scope、CLI、任务写入等约束按问题明示需求一致处理。

无 gold 的负例必须检查非空时间合格库，确认没有直接相关记录。无 gold 不代表模型无法以通用知识回答。对同来源近重复的普通知识负例保留自包含的代表题并记录拒收重复原因；本次执行前检索全部为正例，不能评价该 track 的无关任务误选率。

## 标注、独审和裁决

每条标注记录保留 / 拒收状态、标注者、任务类型、来源类别、scope 证据、gold 集合、逐 gold 理由、参考答案，以及必要的局部答案规则、禁止规则和原题规范化说明。独立审阅者须不同于初标者，核对原候选、正文、时间、scope、来源及最小问题改动，逐条给出通过或修正意见。

审阅批准在本地原件中绑定记忆库、候选和标注对象的完整性摘要，防止批准后静默改材料；摘要本身不替代阅读。发生冲突时统一裁决并保留原意见、最终决定与理由。公开视图不发布这些输入摘要或逐条身份。

本次初标与独立复核均由 AI agents 执行，不是人类金标小组，不能排除同类模型共享偏差。61 条初标最终保留 42、拒收 19。拒收原因包括历史现场证据不足、相关版本晚于问题、请求含糊、机器派发和相邻重复主题；不得把“直接人类请求”当作自动合格。

已裁决的通用边界包括：材料是否私密取决于实际敏感内容，不能仅按文档类别推断；有效的路由 / 契约要求与过时的工具路径分开，旧路径不成为必答事实；更具体且适用的格式约束优先于旧版一般说明。原始具体案例、参考答案和逐条裁决只存本地完整归档。

## 划分、冻结与评估隔离

按整个来源 session 的稳定哈希预先分 dev/test：SHA-256 的前八个十六进制字符转整数后模五，余零进 dev，其余进 test。同来源全部题保持在同一 split；这是按来源划分，不是按时间的未来留出验证。Topic 仍可能跨来源重复，来源聚类不能消除全部相关性。

开发集用于链路、并发和实现检查；正式 test 开始前冻结候选选择、gold、提示词、模型、版本、并发与统计计划。正式结果不能用于挑题、重标、换主指标或调参；新方案另建协议和运行。参考答案、gold、审阅理由和来源标识不进入 Agent workspace；verifier 单独保存。

本轮数据卡在未读取正式 trial 答案或分数时完成，随后正式报告保留完整矩阵、失败和覆盖率。公开聚合数据没有把真实语料替换成合成案例；程序的合成单元测试仅验证实现，与真实实验数据分开。
