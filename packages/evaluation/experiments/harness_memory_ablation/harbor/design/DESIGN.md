# Harbor 三条件真实记忆消融：实验设计

本实验比较 Edges 的分作用域记忆、根目录平铺和无实验记忆，主要问题是：**在相同真实记忆正文与运行条件下，作用域布局及发现索引是否提高前五条记忆选择的召回，以及 token 和时延如何变化。** 主要比较是 scoped−root，不以分层必须获胜为验收标准。

本设计整理自正式 test 开始前冻结的协议和数据卡。机器可读的 [protocol-v1.json](protocol-v1.json) 是该冻结配置的**公开字段视图，不是原始冻结文件，也不能替代其完整性校验**。完整原件统一归入本实验 [local/archive/](../local/archive/)；该目录由 Git 忽略，公开克隆不随附。程序仍位于[本实验根目录](../README.md)。

## 研究对象与处理条件

| 条件 | 正文范围 | 发现方式 |
| --- | --- | --- |
| scoped | 每题全部时间合格记忆，按真实作用域放置 | 真实作用域入口逐层链接本层记忆和最近下层入口 |
| root | 与 scoped 完全相同的时间合格正文 | 共同根目录平铺，根入口与平铺索引 |
| none | 不提供实验记忆和索引 | 保留相同基础工作区与空作用域目录 |

scoped/root 的正文、标题、scope 与日期事实保持一致；不按当前问题作用域预筛候选库。变化同时涉及路径和发现索引，不能单独解释成目录深度的因果效果。三组共享模型、版本、提示词、时限和任务 scope；返回答案以及至多五个不同的已读记忆标识。参考答案、gold、来源标识及 verifier 材料置于 Agent 构建上下文之外。

Agent 运行于重建的记忆工作区，并非当时完整业务代码仓库或服务环境。`memory_qa` 回答历史问题；`pre_task_retrieval` 只选择执行原始请求前应读的记忆，说明适用规则和未知条件，不修改代码、部署、写入或执行原任务。

## 真实数据与历史边界

数据来自单用户有界根观测导出：3,379 行，确定性过滤后 1,724 个候选；目的性选出 61 条由 AI Agent 标注和独立 AI Agent 审阅，保留 42 题。预先按来源 session 分为 dev 11 题 / 8 个来源和 test 31 题 / 23 个来源，两者无来源 session 交集。不是随机代表性抽样，没有逐条全文审阅全部候选，也不是人类金标。

正式 test 包含 24 道正例、7 道负例，11 道问答、20 道执行前检索；已知非根作用域 6 题，共同根或未知作用域 25 题。详细组成见[数据卡](../data/DATA_CARD.md)与[聚合 JSON](../data/dataset-summary.json)，标注与审阅过程见[准则](ANNOTATION_GUIDE.md)。未新造问题、参考答案或 gold 来替代这批真实数据。

语料是框架及公开个人脑已登记 Memory 的固定历史版本：181 份、7 个真实作用域。取 2026-10-31T00:00:00Z 之前的 Git 快照，逐题再严格限定 `available_at < query_at`。`available_at` 为冻结 revision 中该文件路径最近 Git 变更时间，不以 frontmatter 证明更早可用。可见文件最少 117、中位 180、最多 181；若选中版本晚于问题，不自动恢复更早正文。它是保守的固定历史库加时间过滤，既不是完整历史回放，也不是全部个人知识。

## 冻结执行配置

| 项目 | 配置 |
| --- | --- |
| 正式矩阵 | 31 题 × 3 条件 × 3 repeats = 279 trials |
| 模型与推理强度 | gpt-6.1-sol，low；提供方未给出别名背后的模型 revision |
| Harbor / Codex CLI | 0.25.0 / 0.162.1 |
| Agent 时限 / 自动重试 | 180 秒 / 0 次 |
| 并发 | 固定 12 路有界队列，每个 Job 一个 trial、独立 Docker 环境和 separate verifier |
| 提交顺序 / bootstrap | seed 20261108 / 2,000 次 |
| 镜像与源码 | 冻结内容固定的基础镜像和实际运行源码；精确原件随本地归档保留 |
| 停止规则 | 不因观察到的质量提前停止；保留基础设施失败，完成全部计划矩阵 |

正式开始前只看过开发结果。历史开发验收包括真实单路、6 路及 12 路执行，以及 53 项离线检查；12 路资格试跑共 12 trials、零失败、批次 76.11 秒。该次有效采样中的容器工作集峰值为 1,412.4 MiB，Docker 配额 1,970.18 MiB；采样有缺口且不包含 VM、daemon、构建全部开销。这些是冻结前已有的记录，不是本次文档整理重新运行的测试，也不是最大并发能力证明。

各 trial 的身份和执行计划预先确定，完成顺序不改变配对。控制器逐次保存结果；进程启动或收集错误保留为失败，不静默重试。test 开始后不得按结果换题、改 gold、调整主要指标或调参；任何修改另立协议和新输出，原冻结运行保留。运行、准备和离线汇总入口见[程序说明](../README.md)，完整输入与历史输出见 [local/archive/](../local/archive/)。

## 指标定义

| 指标 | 定义和适用范围 |
| --- | --- |
| selected recall@5（主要） | 前五个 selected 与全部相关 gold 的交集数 / gold 数 |
| evidence recall@5 | 上述命中还须在完成工具返回中出现 marker 或可见库内唯一正文片段 |
| marker / content recall@5 | 分别按 marker 与正文片段核验，揭示取证方法差异 |
| precision@5 / MRR | selected 命中数 / 5；第一个正确选择的排名倒数 |
| 无 gold 误选率 / 无效选择数 | 无相关记忆仍选择记忆的比例；选择不存在标识的数量 |
| 局部答案规则 / 禁止规则 | 预声明正则核验；未定义规则时不适用，不是完整语义或任务成功率 |
| token | 实际累计 input、output、cached input；uncached=input−cached，total=input+output |
| 工具数 / 暴露记忆数 | 完成的工具 item 去重数；返回中有正文暴露证据的记忆数 |
| Agent 时延 / trial 墙钟 | 原生 Agent 执行阶段；单个 Job 墙钟含构建、安装、verifier |
| 失败率与覆盖率 | 全部计划尝试中的失败及各指标完整可用题占适用题的比例 |

无 gold 题的 recall、precision 与 MRR 为 N/A，单报误选；none 正例 recall=0 是无实验文件的结构基线，不能证明分层优于平铺。Gold 保留所有直接相关记录，不裁到五条；test 有 7 题 gold 超过五条，正例平均 recall@5 理论上限为 88.72%，单题上限为 `min(5, gold_count)/gold_count`。

取证只看已完成工具的返回内容，不把命令文本、最终答案或标题当正文证据。Marker 和唯一片段表示材料暴露，不证明全文读完、理解正确或因果使用；片段审计也可能漏计格式化、转义或短片段。精确实现由冻结运行里的评分源码决定；当前维护实现见 [metrics.py](../metrics.py)。

未知用量保留 null，不补零；质量失败不伪装成答错，已知资源成本保留。总 token 包含缓存输入，不能直接视为按价格计算的成本。缓存明细缺失时，不将未知 cached/uncached 当零。

## 统计计划与解释规则

每题先平均三次重复，再对适用题等权。某指标少一次重复，该题就不进入该指标完整配对；区分不适用与真实缺失，报告有效题数、覆盖率、来源 cluster 数及失败率。以来源 session 聚类 bootstrap 2,000 次，seed 20261108；报告 percentile 描述性 95% CI，未做多指标或多子集校正。原始 trial 的 p50/p95 描述时延分布；配对差异以每题重复均值计算。

预声明三个比较为 scoped−root、scoped−none、root−none；主要比较为 scoped−root 的 selected recall@5。全部、问答、执行前检索、明确非根作用域、共同根 / 未知作用域均分别报告。任务和作用域是不同划分，不能相加；共同根包含明确全局根和无法映射的外部目录，不全部等同缺少来源。

Recall 区间整体高于零，只支持本数据与协议范围内的收益；跨零表示证据不足。Token 与时延独立报告，允许质量和资源之间存在取舍。12 路并发下的 Agent 时延受共享资源和调度影响，提供方缓存未隔离；不把整批耗时除以 trial 数当独立时延，也不将重叠 trial 时长相加解释为整批耗时。

## 审计、结果与完整归档

正式前审计完整矩阵、提示词等价、记忆正文等价、时间边界、dev/test 来源不重叠和 verifier 隔离。正式后核对原生日志中的累计 token、Agent 阶段时延、冻结评分、所有分层配对统计，并审读工具返回、联网 / 写入行为和资源采样。原始观测、标注、冻结输入、源码、原生执行日志及审计原件均统一保留于 [local/archive/](../local/archive/)，不进入公开 Git；此公开设计不替代原件。

已完成的正式执行为 279/279、零失败、12 路并发、28.63 分钟。公开[报告](../../../../reports/2026-11-09-harbor-memory-ablation.md)给出原始聚合值与区间：整体 recall、token、时延没有明确优势证据，6 题非根作用域子集仅为探索性信号。此结果段用于导航，不改写冻结前协议。

运行审计发现 2 次读取 Codex 内置辅助 Skill；它不属于实验记忆，不计 memory 命中，未见后续联网或写入，也不能由此推断对答案的影响。none 只表示没有实验记忆文件，并非完全没有其他本地材料。提示词禁止联网不等于网络硬隔离。单用户、单模型别名、目的性抽样、AI 标注共享偏差、有限历史库和少量已知非根作用域，均限制推广及因果解释。
