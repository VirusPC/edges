# 自然请求补充集 v2：冻结测试集评估

**按冻结 gold 计分，scoped 的 recall@5 为 97.78%，root 为 100.00%，未显示分层召回优势。语义复核仅确认一个无争议的必要规则遗漏场景，另外两个场景存在 gold 必要性范围歧义，因此不能把全部分差解释为检索失误。scoped 的未缓存输入少 22.76%、Agent 时延短 4.16%，两者描述性区间不含零；总 token 仅少 0.61%，差异区间跨零。**

本次按冻结协议评估 **36 道 test、三条件各重复三次，共 324 次 trial，全部完成、零失败**，固定 12 路并发，批次墙钟 35.11 分钟。结果描述这批纯虚构、来源启发的受控请求，与[开发诊断](RESULTS.md)、[合成 v1](../RESULTS.md)及[真实历史问题评估](../../../../../reports/2026-11-09-harbor-memory-ablation.md)分别报告，不混合计分。

## 为什么执行这次 test

开发阶段发现一个有效漏检场景，未达到预声明的“至少两个独立正例场景非满召回”工程门槛，并暴露必要证据 gold 与相关背景提示之间的评分边界。该事实保持不变。本次是在已知这些局限后追加的冻结测试集评估，用于观察原题集在更多未执行场景中的表现；它不表示 v2 已通过全部开发验收，也不是对质量区分度、统计功效或真实场景代表性的认证。

[测试协议](protocol-test-v2.json)于 **2026-11-09 01:31:32 UTC**、首次 test 模型调用前冻结。题目、语料、gold、提示与评分代码均沿用原 v2；不依据 test 分数换题、修改 gold、选择 seed、自动重试或提前停跑。开发集与测试集的查询实体、来源 session 和具体任务蓝图分离，但共享作者设计分布及全局记忆干扰库；不能把这种划分等同未来真实请求的独立留出验证。

## 执行与测量

配置为 **Harbor 0.25.0、Codex CLI 0.162.1、gpt-6.1-sol / low**，Agent 时限 180 秒，seed 20261110，12 路并发。固定基础镜像及实际运行源码随记录保留，完整配置见测试协议。

| 条件 | 可见材料与发现方式 |
| --- | --- |
| scoped | 时间合格的记忆正文按作用域放置，提供对应发现索引 |
| root | 相同记忆正文及 scope、时间元信息平铺在根目录，提供扁平索引 |
| none | 不提供实验记忆文件及其发现索引 |

scoped/root 的正文与时间可见集合逐条一致，不按问题作用域预先筛掉候选记忆；变化同时包含目录放置与发现索引。每个 trial 使用独立环境，gold 与 verifier 位于 Agent 工作区之外。这里的 none 仅表示没有实验记忆，不表示运行时完全不存在其他辅助材料。

题集按冻结标注含 **30 道非空必要证据 gold 的正例、6 道空必要 gold 的近邻题，36 个来源 session**，来自六类机制、每类六题。起点为根目录 24 题、仓库级 8 题、深层 4 题；32 题为 `source_informed`，4 题为 `targeted_stress`。配额服务于诊断覆盖，不估计真实场景频率。数据及构造依据见[完整题集](data-v2.json)、[覆盖说明](COVERAGE.md)与[数据报告](DATA_REPORT.md)。

主质量指标是相对冻结必要证据 gold 的所选记忆 recall@5，以及其中具有已完成工具输出正文暴露证据的 recall@5。正例 gold 均不超过 5 条，因而没有 @5 容量造成的不可达满分；空 gold 题不混入召回均值。下述必要性范围歧义保留在原分数中，未通过事后改 gold 消除。本文不报告完整答案正确率或原始任务成功率，正文暴露也不证明理解、正确运用或因果贡献。

每题先平均三次重复，再按题等权；scoped−root 使用来源 session 聚类 bootstrap 2,000 次，报告描述性 percentile 95% 区间，不校正多指标与多子组比较。重复执行不增加独立场景数。某题某指标若有重复缺失，该题不进入该指标的完整配对比较；失败、适用题数与完整覆盖率同时披露。

## 漏检复核与集合评分边界

冻结算术结果中，scoped 的 90 次正例执行有 4 次未满召回，涉及 3 个独立场景；root 的 90 次正例执行均满召回。这些数字只描述与原 gold 的匹配，不能自动将三个场景都称为有效漏检。

独立语义复核覆盖全部 4 份未满召回记录及 3 个场景。审阅时隐藏条件和重复编号，披露题目、gold、最终选择与回答，并补查所有具有正文暴露记录的记忆全文以寻找等价替代证据；结论在揭示组别前形成。没有发现其他已暴露记忆能等价替代未选中的 gold，但这仍不能证明各条 gold 在题面允许的所有合理解释下都必需。

| 场景 | 复核结论 | 可支持的解释 |
| --- | --- | --- |
| 档案批量改名 | 文件筛选规则属于当前请求的明确必要约束，既未暴露正文，也未进入最终选择 | 1 个无争议的必要规则遗漏场景 |
| 成果墙 | gold 将要求扩展到完整生命周期；题面也允许较窄的历史决定说明 | 必要性范围与指标解释有歧义，不能直接计为有效漏检，也不据此判 gold 错误 |
| 食盒 | gold 扩展到完整订购流程；题面也允许较窄的替代安排回答。两次执行均已暴露未选 gold 的正文 | 存在必要性范围歧义；固定 gold 的最终 ID 漏选不能称为发现文件失败 |

本批因此只确认 **1 个无争议的有效遗漏场景**，不宣布达到“两场景”的工程诊断门槛，也不将既有 dev 与本批 test 相加来补足门槛。三个场景的原始 gold、分数与区间全部保留，不以运行后解释重算更有利的结果。复核揭示了检索遗漏、最终证据选择和任务必要性范围应分别判断；它不产生新的答案正确率或完整任务成功率。

原 v2 的 gold 定义为“当前请求的必要证据”，提示却允许选择“与问题相关”的记忆。因此 strict precision、集合精确匹配、额外选择数与空 gold 题的非空选择率，均只描述选中集合相对固定 gold 的差异。正确用于说明历史、适用范围或为什么不采用旧办法的背景，也可能落在 gold 之外；不能把这些集合差异直接命名为语义错误率或误用率。

附加集合数字如下，全部保留冻结 gold，不作语义错误判定。

| 相对固定 gold 的集合诊断 | scoped | root | none |
| --- | ---: | ---: | ---: |
| 所选集合精确匹配 | 51/108（47.22%） | 74/108（68.52%） | 18/108（16.67%） |

| 空必要 gold 题的非空选择 | 10/18（55.56%） | 6/18（33.33%） | 0/18（0%） |

精确匹配按全部 36 题的重复均值汇总；因各题重复数一致，数值也等于上表 trial 比例。Precision 的分母是实际选中数，空选为 N/A；只纳入三次重复均适用的完整题，所以两组覆盖不同，不能直接把两个均值相减当成配对语义优劣。累计额外选择和 18 次空 gold 执行也不是独立场景数：后者仅来自 6 题各重复三次。

这些集合诊断未对全部 gold 外选择做逐条语义裁决，不据此声称误用率。诊断导出器保留了 “Development observations are not held-out effectiveness evidence.” 的旧固定说明；本批的 manifest 和导出 `split` 均为 `test`，该遗留文案不改变本批是冻结 test 扩展评估的事实。

## 用量、验证与结论适用范围

本批原生累计用量为 **32,129,714 tokens**：输入 31,946,451，其中缓存输入 26,036,480；未缓存输入 5,909,971；输出 183,263。缓存输入占总 token 的 81.04%。此处不含既有 dev、数据编写、主会话或审阅 Agent 的用量，也不是计费金额。总 token 包含缓存输入，不能仅由总 token 推算费用或额度占比。

完整性与原生计量审计完成 **15,141 项核对、零错误**；独立统计审计完成 **9,496 项核对、零不一致**，324 份原生日志的 token 独立汇总也一致。审计范围与收据见 [TEST_VALIDATION.md](TEST_VALIDATION.md)。语义遗漏的结论按上节单独披露，不由这些算术检查代替。

资源记录共 431 帧，其中 408 帧有活跃容器；活跃帧里 279 帧内存采样完整，129 帧 stats 返回非零或采样不完整。OOM 状态查询有 161 个错误帧，已获得的样本里未见 OOM 阳性，但不能断言整批没有 OOM。观测容器内存峰约 1.415 GB，是采样下界；原生 Agent 执行重叠峰为 12，开头未漏采。这些记录不是完整网络隔离、文件系统无改动或工具语义合规的证明。

本次证据只适用于这组受控请求、固定模型配置与导航协议。合成题从少量真实开发请求抽取抽象特征后重新虚构，不是随机代表抽样；模板与作者偏差、单模型预算、共享缓存和并发调度仍限制推广。资源时延来自并发中的 Agent 阶段，不是独立执行时延或纯文件系统耗时；资源采样的观测峰值也不是完整基础设施峰值。

scoped/root 的差异包含目录位置与发现索引，没有分离纯目录深度效应，也未覆盖所有优化过的扁平检索方案。本实验只评估重建工作区中的记忆检索与解释，不测完整业务环境、长期在线记忆写入、用户澄清交互或原始操作完成率。开发、测试及前两批实验的结论各自保留，不将它们混成一个总体分数。
