## 冻结与统计

- 运行前预检 2,199 项通过；29 项输入 SHA-256 在执行前后全部一致。数据、gold、提示、运行与评分代码均未修改。
- 完整性与原生计量审计 15,141 项通过，零错误：矩阵、条件正文一致性、verifier 隔离、评分、原生用量、时延、配对统计及报告均核对。
- 独立实现完成 9,496 项检查，零不一致；未导入现有评分/统计模块，另行计算 gold 召回、按题均值、覆盖率、2,000 次聚类 bootstrap 区间和 324 份原生日志 token 求和。
- 30 个正例场景用于召回，36 个场景用于资源统计；适用指标完整覆盖率均为 100%。检查项数量不等于独立样本量。
- 公开数值报告只增加 v2 解释说明与集合指标标签，数值 tracks 与原导出一致，trial CSV 逐字节一致。未根据复核改写 gold 或重算事后“修正分”。

## 正例未满召回的语义复核

复核覆盖两种有记忆条件中全部 4 次成功但 fixed-gold 召回未满的执行，涉及 3 个场景。审阅时隐藏条件与重复编号，披露 gold，并补齐所有已观察到的记忆正文；裁决前未读取组别映射或原始 trial 表。审阅由独立 AI Agent 完成，不是人类金标共识。

- 扫描件批量改名：1 个明确的必要规则遗漏场景；文件筛选与排除临时件规则没有被暴露、选择或在答案中覆盖。
- 成果墙与食盒：2 个场景存在必要性范围歧义。Gold 要求完整生命周期或订购流程，题面也允许较窄的历史决定与替代安排解释；不无条件判为语义失败，也不直接宣布 gold 错误。
- 食盒的两次执行已暴露遗漏 gold 正文，不能称为没找到文件。补齐其余已读正文后，没有发现等价替代事实。

因此不宣布两场景质量诊断门槛已明确达成，不把 4 次执行或多条遗漏当成 4 个独立场景。全部额外背景选择、满分回答和完整任务成功率未纳入这次语义审阅；strict precision、集合精确匹配和空必要 gold 非空选择率仍只是相对固定 gold 的算术诊断。

## 原生工具行为

完整审阅 324 份日志、1,373 次 completed 命令、705 个不同表达式；仅将合成记忆哈希归一化展示为 610 个完整语义视图，逐一审阅并保留原表达式到分类的映射。1,373 组 started/completed 闭合，与主审计导出的命令一致，未审项为零。

未观察到 Agent 联网命令、显式内容修改、执行原任务或读取非实验辅助文档正文。100 个 none trial 存在 105 次越出实验工作区的只读探查，包括 12 次广域文件名搜索；输出核对仅见共享 README、文件名/目录元数据、Git 状态与不存在提示。类别可能重叠。

另有 29 条 Codex 运行时模型目录刷新超时告警，涉及 27 个 trial；全部执行仍成功。这些是运行时元数据请求，不是 Agent 的网络检索命令。日志命令审阅不能代替网络抓包或文件系统差分，不排除运行时、缓存或 Git 元数据的隐式写入，也不是网络硬隔离证明。

## 资源采样与用量

资源记录共 431 帧，408 帧有活跃容器；279 帧提供完整内存样本，129 帧的 stats 调用非零退出，另有 161 帧 OOM 状态 inspect 错误。样本未记录 OOM 阳性，不能由此证明全程无 OOM。观测容器工作集峰值约 1.415 GB，只是下界，不包含完整 Docker VM、daemon 或构建开销。原生 Agent 阶段并发峰值为 12，首个样本前没有 Agent 启动漏采。

本批累计 32,129,714 tokens：输入 31,946,451、输出 183,263；缓存输入 26,036,480、未缓存输入 5,909,971。缓存输入占累计总量 81.04%。不包含数据构造、开发运行、主会话或审阅 Agent，不等同费用或账户额度比例。
