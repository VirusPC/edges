## 工具行为与执行边界

独立审阅覆盖全部 36 份直接原生日志、152 条 shell 命令（126 种完整命令）与 108 份输入原件摘要。143 个含 shell 的原始编排调用和对应输出闭合：134 次单调用、9 次双调用；另有 1 次仅枚举可用工具元数据，没有调用搜索工具。

观察到的命令为目录、文件、内容搜索及 Git 元数据只读诊断，没有发现模型执行联网命令、显式持久文件修改、外部业务操作或实验外正文读取。none 条件有 11 条工作区外路径或全局指令探测，涉及 10 个 trial；连同 Git 元数据诊断共 13 条，已逐项核对返回内容。不能把“未读到外部正文”写成“从未探测工作区外”。

19 个 shell exit 1 属于搜索无结果或初始工作目录无索引，均有完整工具结果；原生 trial exception 为 0。日志中还有 18 行 CLI 模型目录刷新超时，涉及 14 个 trial，但 36 个模型 turn 均正常终结。这些运行条件如实保留，不等于所有底层请求均无异常。

日志未观察到模型外联不构成网络硬隔离证明。Docker 网络仍用于安装和模型访问，目录探测不证明不存在所有侧信道；返回正文只证明暴露，不证明理解或答案正确。

## 资源观测与语义解释

资源监测在模型开始前启动，原生 Agent 最大重叠为 12。共 54 个样本，其中 41 个有活动容器，26 个具有完整内存数据；15 次 stats 返回非零、14 次 OOM 状态查询有缺口。完整采样中观察到约 1.46 GB 的容器工作集峰值，仅为观测下界，不是 VM/daemon 总内存或真实最大峰值；未观察到 OOM 帧也不能证明没有 OOM。

隐藏条件名的质量复核覆盖 24 个有记忆 trial，以及 9 个非精确集合的回答。有效漏检只有 1 个正例场景，不满足两场景门槛；12 次 gold 外选择都被正确用于对照说明，无法据其认定错误套用规则。两道空 gold 负例均涉及必要性与相关性契约边界。因此完整性和计量审计通过后，[结果解释](RESULTS.md)仍保留这些实质限制。

原件及收据分别位于 Git 忽略的 `local/synthetic-v2/`、`local/support/v2-native-review/` 与 `local/support/v2-quality-review/`。来源画像、候选和数据审阅也在同一实验的本地支持区；公开目录不包含真实问题、私密来源标识、宿主路径、原始回答或命令。哈希用于绑定已审材料，不单独证明材料真实性或审阅者独立性。
