# 合成记忆消融正式实验：验证与审计

正式矩阵为 **32 题 × 3 条件 × 3 次重复，共 288 次 trial**，固定 12 路并发。全部执行完成，记录的执行失败为零。本文件报告执行、计量和统计核验，不把审计通过解释为答案正确率或真实任务收益。

实际运行源码基线为 `c9f2d71c3dfd094a598ad98dddb0689f6f885882`。9 个归档运行程序均与起跑前源码和运行清单匹配；其中 7 个核心评测程序与 dev 相同。冻结协议、数据、计划与运行来源一致，dev/test 来源 session 无交集。集成离线测试 **105 项全部通过**。

自然语言 gold 的独立复核覆盖 **40/40 题**，复核范围与判据见 [REVIEW.md](../../REVIEW.md)。这项内容复核与下述运行、取证及算术检查分开；程序一致性检查不能替代 gold 语义审阅。

## 工具行为审阅

工具终审覆盖 **288 份原生日志、940 次命令调用、508 条不同命令**。日志缺失、未终结工具和未审项均为零；导出的命令与原生日志一致。

全量语义审阅在 Agent 的工具操作中，未发现联网、写入文件、执行原任务或读取实验工作区外文件正文的证据。共有 **103 次环境探测，涉及 85 个 trial**；其中一次仅枚举到运行时凭据文件的路径，未读取正文。此处不公开具体路径或命令。

另有 **27 条模型目录刷新超时诊断，涉及 22 个 trial**，均最终执行成功。这些是运行时诊断，单独记录，不等同于 Agent 发起的外部工具操作。原生运行时安装和模型 API 访问也与 Agent 的工具行为分开。

工具日志审阅不是网络抓包或完整文件系统差异证明。任务提示限制联网，不代表网络硬隔离；未发现上述行为也不等于答案正确、gold 完整或记忆架构产生了真实收益。

## 资源观测与采样缺口

监测在正式执行期间只读采样，没有调整并发或容器资源。共 **351 帧**，其中 **204 个活跃完整帧**；包含无活跃容器时的帧后，完整帧合计 223，不完整帧 128。

| 观测量 | 结果 |
| --- | ---: |
| 完整活跃帧的容器内存峰值 | 1,245.53 MiB |
| 上述峰值占 Docker 内存配额 | 63.22% |
| 完整活跃帧的容器 CPU 合计峰值 | 157.01%，约 1.57 核 |
| 原生 Agent 阶段重叠峰值 | 12 |
| 开头 Agent 执行漏采 | 0 秒 |
| stats 失败帧 | 128 |
| OOM 状态 inspect 失败帧 | 149 |
| 观测到 OOM 阳性的采样帧 | 0 |

采样间隔中位数约 5.006 秒，最大约 5.220 秒；监测以完成且无活跃实验容器的状态正常结束，没有中断。整批执行墙钟约 28.3075 分钟，不等于单个 trial 独立执行时延。

128 帧 stats 失败与 149 帧 OOM inspect 失败可能重叠，不能相加成独立缺失帧。没有足够信息逐帧确定失败原因，不能全部归因于容器生命周期竞态。OOM 是采样时的容器状态，已经移除的容器和采样间隙可能被遗漏；**零阳性采样帧不能证明全程无 OOM**。

内存数值是 Docker 报告的容器工作集，不是精确进程 RSS，也不包含完整 Docker VM、daemon 和 build 开销。离散采样和失败帧使峰值只是观测下界；配额减去该数值不是真实可分配余量。此次成功完成不能用于推断硬件最大并发容量。

## 解释边界与复现入口

这是一组受控合成场景，实体共享生成模板，不等于从真实任务总体独立随机抽样。提供方缓存未隔离，并发时延受共享宿主、调度与服务影响。scope 放置和发现索引同时变化，不能将差异单独归因于目录深度。none 的正例 recall 零是没有实验记忆文件的结构性基线。

本次未根据正式结果换题、改 gold、调参、重试或更换主要指标。验证结论是冻结实验可追溯、所查计量及统计一致；效果判断仍须结合主指标、分母、区间、覆盖率和数据适用范围。审计本身不证明语义正确、任务成功或对真实用户的普遍收益。

可复用的离线核验与资源采样方法见 [审计入口说明](../../../audit/README.md)。原生日志、逐条审阅依据和审计输出保留在本地归档；本文件仅发布聚合验证结论。
