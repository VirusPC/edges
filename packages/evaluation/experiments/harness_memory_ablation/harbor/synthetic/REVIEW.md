# 合成数据的独立验证器

[review.py](review.py) 从 Agent 可见的中文记忆正文和问题重新解析业务、主题、作用域、受众与有效期，独立求出当前适用规则，然后才比较存储的 gold 与参考答案。它不导入生成器或作者的 oracle，也不使用 `scene_truth` 推导答案。它同时核对公开协议、构建清单和 runner 的合成提示词。

这是针对 **synthetic-scenes-v1 五类模板的约束解析器，不是通用语义正确性证明**。首次场景审阅由不同于生成作者的 Agent 完成；可重复执行的程序检查保留该次独立推导，但不替代新增模板的人类或独立 Agent 审阅。

## 运行

在 Harbor 实验根目录执行，无需模型、SDK、网络或凭据：

```bash
python3 -B synthetic/review.py

python3 -B synthetic/review.py \
  --dataset synthetic/data-v1.json \
  --protocol synthetic/protocol-v1.json \
  --runner run.py \
  --output synthetic/REVIEW.json
```

三个输入默认定位到本模块相邻的公开文件，与启动工作目录无关。默认仅将 JSON 输出到 stdout；`--output` 显式保存结果。成功退出码为 0，失败为 1，并给出固定诊断，不回显本机路径或输入正文。输出仅含状态、固定说明、聚合计数和公开文件摘要；不复制题目、答案或日志。

`review_data(data)` 是不写文件的 Python 入口，适合检查另一个 seed 或干扰规模生成的同版本数据；它不固定题数、业务数或可见记忆数。完整 CLI 另要求对应的公开冻结协议及同目录构建清单。新数据应配套新协议和构建产物，不能绕过旧数据摘要或覆盖旧冻结输入。

## 检查范围

- 严格解析五种问题模板及记忆正文，未知模板直接拒绝；检查正文与 scope、title、available_at 元信息一致。
- 从问题确定请求的业务与主题，从正文按祖先目录、受众、可用时间和有效期筛选，再按更深作用域及同层最新有效版本求解；并列赢家视为歧义而拒绝。
- 解完后核对全部 gold，拒绝缺失、额外、重复或未来证据；逐条核对参考答案中的业务与事实。算术负例独立计算结果，无适用业务规则。
- 检查问题不含记忆标识、路径或正例答案数字提示，业务与来源 session 不跨 dev/test，题目 family、任务类型和起始 scope 一致。
- 绑定 dataset、protocol、构建清单、runner 和本验证器摘要；检查协议的 split 与测试 family 规模。仅解析并执行 runner 中允许的纯表达式 `instruction` 函数，不导入或运行 runner 模块。
- 确认所有合成提示明确区分多个目标业务的适用规则，且不将合成题称为真实历史用户题。

本版本只覆盖无 `answer_checks` 的检索评估。三臂渲染后的完整隔离、内容等价、执行矩阵、真实用量和工具行为须由运行期审计另行验证；通过本程序不等于模型答案正确、真实任务成功或分层有收益。

## 当前冻结输入的结果

[REVIEW.json](REVIEW.json) 由本验证器实际运行产生，与 [protocol-v1.json](protocol-v1.json) 绑定。

| 检查 | 结果 |
| --- | ---: |
| 全部题目 / 独立核对的请求事实 | 40 / 85 |
| 正文与元信息一致 | 682 / 682 |
| Gold 与独立重解一致 | 40 / 40 |
| 歧义赢家 / dev-test 业务交集 | 0 / 0 |
| 虚构业务域 / 每题可见记忆 | 96 / 586 |
| 合成多业务提示核对 | 40 / 40 |

发布验证器时，另在内存副本中替换正例 gold、改写正例事实、改变问题请求，均确认被语义检查拒绝；检查发生在协议摘要验证之前。使用另一个 seed 和不同干扰规模的同版本生成数据也通过 `review_data`，避免把默认计数写死为通过条件。冻结数据与现有运行未被改动。

当前 local 题的简单词法 recall 已为 1，质量上限空间因 family 而异；其余题也不能保证 scoped 优于 root。词法诊断不是 root 模型臂的实验结果。未来记忆不可见验证的是时间过滤，已过期但可见的版本才检验时间解释。模板和策略主题在 dev/test 间共享，因此结果不能推广为未见真实语言或真实工作任务的普遍表现。
