# Harbor 真实记忆消融：公开聚合报告（2026-11-09）

**这批数据尚不能证明分层记忆在整体 recall@5、token 或速度上优于根目录平铺。** 分层的整体召回率点估计高 1.70 个百分点，但描述性 95% 区间为 −4.06 至 +6.54 个百分点，跨过零。预先声明的「明确非根作用域」子集有正向信号，但只有 6 题，只能作为探索性信号。

正式实验使用 **31 道真实测试题、23 个来源 session、181 份历史记忆**。每题三组各重复三次，**279/279 成功、零失败**，固定 **12 路并发**；整批墙钟 **28.63 分钟**。本页公开聚合结果与解释边界；原始会话、问题、答案、来源标识、冻结数据和逐次运行日志非公开。

程序与运行说明：[Harbor 三条件实验](../experiments/harness_memory_ablation/harbor/README.md)。可机器读取的结果：[聚合 JSON](2026-11-09-harbor-memory-ablation.json)。

## 条件与测量口径

| 条件 | 内容 |
| --- | --- |
| scoped | 将时间合格的记忆正文按作用域放置，并提供对应发现索引 |
| root | 同一批记忆正文平铺到共同根目录，并提供平铺索引 |
| none | 不放实验记忆文件或其索引 |

模型为 `gpt-6.1-sol`，推理强度 `low`；Codex CLI `0.162.1`，Harbor `0.25.0`，Agent 超时 `180` 秒。提示词版本 `three-arm-historical-retrieval-v2`；test split、每条件重复 `3` 次、seed `20261108`，完整执行冻结矩阵。没有根据正式结果换题、改 gold、调参、重试或更换主要指标。

主指标是所选相关记忆 recall@5。先平均每题的三次重复，再按题等权；无相关记忆的负例不混入 recall 均值，另报误选率。资源均值覆盖全部测试题。总 token 为累计 input+output（包含缓存输入），未缓存输入为 input−cached input；未按价格换算费用。Agent 时延来自原生执行阶段；trial 总时延另含构建、安装与验证，完整均值和原始分位数见 JSON。整批墙钟不含准备、镜像检查及最终统计，重叠 trial 的时长不能相加作为整批耗时。

## 数据、审计与解释边界

- **单用户目的性抽样，非人类金标。** 数据从 3,379 条根观测中形成 1,724 个自动候选，目的性选出 61 条由 AI Agent 标注并由独立 AI Agent 复核，最终保留 42 题：31 test（23 个来源 session）、11 dev（8 个来源 session），两者无来源 session 交集。未逐条全文审阅全部候选，也非随机代表性样本；同类模型可能共享标注偏差，跨 session 的主题相关性仍可能存在。
- **有限历史记忆范围。** 语料仅包含框架及公开个人脑中已登记的 181 份历史 Memory，并非全部个人知识、笔记、技能、业务代码或完整私密资料。逐题严格使用 Git 版本时间早于问题的文件；测试题可见数量最小 / 中位 / 最大为 117 / 180 / 181。固定历史文件版本加时间过滤不等于完整历史回放，Git 提交时间也不等于首次可知时间。
- **处理条件有边界。** scoped/root 的时间合格正文相同，变化同时包含目录位置与发现索引，不能将结果归因为纯目录深度。运行在重建记忆工作区，未恢复完整历史业务环境；执行前检索只选取应读记忆，不执行原始任务。正文暴露证据不证明理解或因果使用。
- **运行时并非完全无辅助材料。** 工具审计发现 2 次读取 Codex 自带的 `openai-docs/SKILL.md`；这不属于 181 份实验记忆，不计入 memory 命中，未见后续联网或写入，也不能据此断言影响答案。none 仅表示没有实验记忆文件，不表示运行时没有其他本地材料。提示词约束联网不等于网络硬隔离。
- **并发和缓存限制。** 固定 12 路并发，提供方缓存未隔离；时延与未缓存输入可能受到共享资源、调度和缓存影响。资源采样未记录到 OOM，但遗漏开头部分执行且存在不完整采样帧；观测峰值不代表完整基础设施峰值，不能据此推算无限并发能力。
- **冻结结果已离线复核。** 279/279 次结果经独立审计，9,379 次核对零不一致；预定抽核 36 次 trial、67 份正文暴露见证全部通过。279 份日志、993 次工具调用、460 条独立命令经工具行为审计，未发现 Agent 联网、写入或执行原任务的证据，日志无缺失。这些是本次已执行审计的聚合记录，非公开日志的替代品。
