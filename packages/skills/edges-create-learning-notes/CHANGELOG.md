## [0.1.0] - 2026-11-14

### Added

- **边学边记。** 学习文章、视频、播客或代码时，可以要一份分成 Summary 和 Comments 的笔记，并在同一份里继续补。Summary 只写材料本身讲了什么；Comments 用启发、质疑、联系、行动记下自己的看法。
- **写进笔记库。** 在 Edges 仓库里交给技能 `edges` 写入 `notes/`，标题用材料标题。更新时改原来那份，不另起一份。仓库之外则存成指定位置的 Markdown 文件。
