# 命名与定位

> 日期: 2026-10-12（Asia/Shanghai）。项目桩，记录当时的用词，不是架构定稿。

- **personal workspace** = 地盘。人和 Agent 落文件、做事的地方。
- **personal harness** = 约束 Agent 的外壳。规则、记忆、技能和入口用来管住进这块地盘的 Agent。
- **edges** = harness on workspace。VirusPC/edges 是套在这块个人地盘上的 harness，也是外脑：多个 Agent 共用同一份仓库。

这和 2025–2026 年 personal agent 的 memory、wiki、routine 潮流同向。本项目把约束和经验放进 PR、git 和 `AGENTS.md`：进仓库，经分支与合并留下。

routine 的跨平台定义见 [`projects/routines/`](../routines/)。
