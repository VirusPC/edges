# personal-agents & harness & workspace

peng cheng 的个人主题：多 Agent 怎么围着一个人的外脑工作。现在是活的项目桩，架构以后再写。

VirusPC/edges 是这份外脑。多个 Agent 共用这一个仓库里的规则、记忆和入口。

三个词先分开：

- **personal agent**：长期为同一个人服务的 Agent。它面对的是这个人的外脑。
- **personal harness**：约束 Agent 的外壳。规则、记忆、技能和入口写在这里。
- **personal workspace**：地盘。文件和日常工作落在这里；harness 配在这块地盘上。

本仓是套在这块个人地盘上的 harness。

routine 的跨平台形态在 [`projects/routines/`](../routines/)，不在本目录展开。
