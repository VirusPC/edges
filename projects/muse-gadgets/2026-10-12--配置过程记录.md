### 安装依赖与 ESP-IDF v6.0.1

- 把登录账号加进 `dialout` 组（`sudo usermod -aG dialout <用户>`，重新登录后生效）。
- 按 Espressif 文档装好依赖：`git wget flex bison gperf python3-venv cmake ninja-build ccache libffi-dev libssl-dev dfu-util libusb-1.0-0`。
- 在 `~/esp/esp-idf-v6.0.1` 浅克隆 v6.0.1（`--recursive --depth 1 --shallow-submodules`），再运行 `./install.sh esp32s3`。
- 克隆 Muse Gadget SDK 到 `~/muse-gadget-sdk`。
- 踩坑：长时间任务别依赖 SSH 前台。一开始用 tmux 跑，结果会话无声无息地挂了；改成 `nohup … > log &` 再轮询日志才稳。
- 踩坑：`idf_tools.py install` 要从 GitHub 下载 ESP32-S3 工具链（几百 MB），国内网络下长时间停在 0%，看起来像卡住了。杀掉后改用 Espressif 国内镜像 `IDF_GITHUB_ASSETS=dl.espressif.cn/github_assets`，再加上 pip 清华镜像 `PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple` 重新执行，很快就装完了。光克隆 ESP-IDF 源码就用了大约 15 分钟。

### 编译 Waveshare 1.75 固件（暂不带 token）

- 1.75 属于上游「完整 UI，手动构建」那一类，在 `~/muse-gadget-sdk/esp32` 下先执行 `. ~/esp/esp-idf-v6.0.1/export.sh`，再运行：

```
idf.py -B build-muse-waveshare-s3-175 -DIDF_TARGET=esp32s3 \
  -DSDKCONFIG=build-muse-waveshare-s3-175/sdkconfig \
  -DSDKCONFIG_DEFAULTS="sdkconfig.defaults;devices/sdkconfig.muse;devices/sdkconfig.muse-waveshare-s3-175" build
```

- 16 线程大约 3 分钟编完，共 2205 步，app 大小 0x211000，4 MB app 分区还空着 48%。唯一的警告是「No SDK token」。
- Secure Boot 和 flash 加密默认都是关的，不会烧 eFuse，也不要打开。
- SDK token 是**编译期**写进固件的（`CONFIG_GADGET_SDK_TOKEN`，格式是 `mgst_…`），从 Muse 账号的 SDK tokens 页面获取。它不是环境变量，配对时也不会另外写进去。所以拿到 token 后要改 build 目录里的 `sdkconfig` 再重新编译。token 绝不能提交进仓库。
- -G 版：SDK 里没有 GPS 相关代码；LC76G 的 I2C 地址是 0x50 和 0x54，和固件用到的地址不冲突。实机上会不会有问题，要看第一次启动的日志。
