## 2026-10-12

### 确认两块板都没有 NFC

核对过 M5Stack StickS3 和 Waveshare ESP32-S3-Touch-AMOLED-1.75-G，两块都没有 NFC。

### 确认上游支持 Waveshare 1.75

[Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk) 的支持列表里有 Waveshare 1.75。-G 版仍没有单独列出，这块板能不能直接用还没在硬件上验证。

### 决定在 minigtr 上通过 Tailscale SSH 编译

编译放在家里的 Ubuntu 主机 minigtr 上，从 Mac 经 Tailscale SSH 进去做。

### 第一次 SSH 没有连上

这一次卡在两处，都还没进入主机：

- Mac 上的 Tailscale 没有启动。
- Tailscale SSH 还要在浏览器里再做一次认证。认证页面的地址不记在这里。

### SSH 连通，板子识别正常

改从 Grok Bot 云端电脑（也在同一个 tailnet 里）SSH 进 minigtr，完成浏览器认证后连上了。

- 板子走 ESP32-S3 原生 USB，识别为 `/dev/ttyACM0`，`lsusb` 显示 `303a:1001 Espressif USB JTAG/serial debug unit`，不需要额外装串口驱动。
- 主机自带 git 和 python3，但没有 cmake、ninja，也没有 ESP-IDF。
- 登录账号不在 `dialout` 组里，直接访问串口会报权限不足。

### 安装依赖与 ESP-IDF v6.0.1

- 把登录账号加进 `dialout` 组（`sudo usermod -aG dialout <用户>`，重新登录后生效）。
- 按 Espressif 文档装好依赖：`git wget flex bison gperf python3-venv cmake ninja-build ccache libffi-dev libssl-dev dfu-util libusb-1.0-0`。
- 在 `~/esp/esp-idf-v6.0.1` 浅克隆 v6.0.1（`--recursive --depth 1 --shallow-submodules`），再运行 `./install.sh esp32s3`。
- 克隆 Muse Gadget SDK 到 `~/muse-gadget-sdk`。
- 踩坑：长时间任务放在 tmux 里跑，日志用 pipe-pane 写到文件，避免 SSH 断开时把安装进程一起带掉。
- 踩坑：`idf_tools.py install` 要从 GitHub 下载 ESP32-S3 工具链（几百 MB），国内网络下长时间停在 0%，看起来像卡住了。改用 Espressif 国内镜像加速：`export IDF_GITHUB_ASSETS=dl.espressif.cn/github_assets`。
