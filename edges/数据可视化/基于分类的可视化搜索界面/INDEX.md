# 基于分类的可视化搜索界面

1. 层次分类（手工分类）
    1. 手工整理加标签
    2. Superbook
2. 层面分类（半自动分类）
    1. 根据数据特征做分组。如 如eBay和淘宝等允许用户分 别对价格、颜色和尺寸各自限定查询范围．  
    2. Flamenco  使用多级层面搜索界面对固定大 小的文档集进行搜 索  
    3.  层面分类同样面临数据尺度带来的分类难题， 自动抽取层面是主要的解决办法  
3. 自动聚类（自动分类）
    1.  统一聚类。 基于单个共同的特征分组  
    2. 多元聚类  。 基于多个共同特征、根据总体相似性对文档分组  
4. 社会化分类
    1.  依赖于网络上用户的标注
