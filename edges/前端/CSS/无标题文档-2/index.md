以下是国内大厂（如字节跳动、阿里巴巴、腾讯等）前端面试中常见的 CSS 面试题（仅列出问题）：

***

### 基础知识

1. CSS 的优先级规则是怎样的？`!important` 的作用是什么？
2. 解释 CSS 盒模型以及其两种模式的区别（标准模式和怪异模式）。
3. 什么是行内元素和块级元素？它们的区别是什么？
4. CSS 中的 `z-index` 是如何工作的？什么是层叠上下文？
5. `position` 的取值有哪些？它们的区别是什么？
6. 伪类和伪元素的区别是什么？举例说明。
7. CSS 的单位有哪些？`px`、`em`、`rem` 和 `%` 的区别是什么？
8. 如何实现 CSS 的继承？哪些属性是可继承的？
9. 什么是 CSS 的重排（Reflow）和重绘（Repaint）？如何优化？

***

### 布局与样式

10. 如何实现水平居中和垂直居中？有哪些方法？
11. Flex 布局的常见属性有哪些？如何实现子元素等比例分布？
12. Grid 布局的基本概念是什么？与 Flex 布局的区别是什么？
13. 如何实现两栏布局、三栏布局？
14. 如何实现一个固定宽高比的盒子？
15. 浮动（float）的工作原理是什么？如何清除浮动？
16. 如何实现响应式布局？媒体查询的基本语法是什么？
17. 如何实现文字溢出显示省略号（...）？
18. 如何实现自适应图片布局，避免图片变形？
19. 如何实现一个固定在底部的页脚？

***

### 动画与过渡

20. `transition` 和 `animation` 的区别是什么？
21. 如何使用 `@keyframes` 实现 CSS 动画？
22. 如何实现一个元素的淡入淡出效果？
23. CSS 动画和 JavaScript 动画的区别是什么？各自的优缺点是什么？
24. 什么是 `transform` 属性？有哪些常见的应用场景？
25. 什么是 `will-change` 属性？如何使用它优化动画性能？

***

### 高级应用

26. 什么是 BFC（块级格式化上下文）？如何触发 BFC？
27. 什么是 CSS 变量（Custom Properties）？如何使用？
28. 如何实现一个多列等高布局？
29. 什么是 `clip-path`？有哪些实际应用场景？
30. 如何使用 `background` 实现多重背景？
31. 什么是 `object-fit` 和 `object-position`？它们的应用场景是什么？
32. 如何使用 CSS 实现图片懒加载？
33. 如何实现一个自定义的滚动条样式？
34. 什么是 Critical CSS？如何提取关键 CSS？

***

### 性能优化

35. 如何优化 CSS 文件的加载速度？
36. 什么是 CSS 的文件拆分和合并？如何实现？
37. 什么是 CSS 的渲染阻塞？如何避免？
38. 如何减少重排和重绘的次数？
39. 什么是 `content-visibility`？它如何优化性能？
40. 如何使用 `prefetch` 和 `preload` 优化资源加载？

***

### 新特性与趋势

41. 什么是 CSS-in-JS？与传统 CSS 的区别是什么？
42. 什么是 Web 字体（@font-face）？如何加载自定义字体？
43. 什么是 `backdrop-filter`？有哪些实际应用？
44. 什么是媒体查询的 `@supports`？如何使用它检测 CSS 支持情况？
45. 什么是 `container query`？它与媒体查询的区别是什么？

***

这些问题涵盖了 CSS 的基础、布局、动画、性能优化以及新特性，针对国内大厂的面试需求具有较强的针对性和实用性。
