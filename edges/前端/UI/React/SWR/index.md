# SWR

<font style="color:rgb(68, 68, 68);">SWR本质上是一种数据获取并且自动处理缓存的库，而非Axios这种HTTP请求库，所以用途主要还是GET获取数据，而非提交修改数据的请求。</font>

如果想结合post用，<font style="color:rgb(68, 68, 68);">useSwr的第二个参数传入一个promise即可，promise里可以写post、put等请求</font>
