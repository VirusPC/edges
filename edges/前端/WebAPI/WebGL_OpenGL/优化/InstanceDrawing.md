核心思想是，通过把类似的对象打组到同一个drawcall中，减少drawcall。

在OpenGL中，使用实例化绘制（instance drawing）时，着色器中的变量和uniform常量会受到不同的影响：

1. **普通变量**：在着色器中，普通变量（如顶点着色器的输入变量）在每个实例的绘制过程中都会被重新计算。这意味着每个实例会根据其自身的数据来计算这些变量。

2. **Uniform常量**：uniform变量在所有实例之间是共享的。它们在一个绘制调用中保持不变，不会因为实例的不同而改变。这使得uniform变量适合用于传递在所有实例中相同的参数或配置，例如光照参数、视图矩阵等。

3. **Instanced属性**：如果使用诸如 `gl_InstanceID` 这样的内建变量，或者通过实例化数组传递的数据（例如通过 `glVertexAttribDivisor` 设置的属性），则可以在实例之间传递不同的数据。这些数据可以用于在着色器中区分不同的实例。

### 概念

实例化绘制是一种优化技术，用于在渲染场景中重复绘制多个相同或相似的对象。它允许通过单一的绘制调用来渲染多个实例，从而减少 CPU 与 GPU 之间的通信开销，提高渲染效率。

### 工作原理

* **单一绘制调用**：使用 `glDrawArraysInstanced` 或 `glDrawElementsInstanced` 等函数，可以一次性绘制多个实例。
* **数据传递**：通过顶点属性和实例化数组（使用 `glVertexAttribDivisor`）传递每个实例的独立数据，比如位置、颜色、变换矩阵等。
* **实例化变量**：在着色器中可以使用 `gl_InstanceID` 变量来获取当前实例的索引，以便在着色器中进行实例间的差异化处理。

### 优势

* **性能提升**：通过减少绘制调用次数，降低了 CPU 与 GPU 之间的通信负担。
* **内存效率**：共享顶点数据，减少了内存使用量。
* **灵活性**：允许在着色器中根据实例 ID 进行动态调整，使得每个实例可以有不同的视觉效果。

### 应用场景

* **粒子系统**：大量相似的粒子可以通过实例化绘制进行高效渲染。
* **植被渲染**：例如树木、草地等重复元素。
* **建筑群**：城市中的建筑物、街灯等。

### 实现步骤

1. **准备顶点数据**：创建顶点缓冲对象（VBO）和顶点数组对象（VAO）。
2. **设置实例化属性**：使用 `glVertexAttribDivisor` 来指定哪些属性在实例之间变化。
3. **编写着色器**：处理实例化变量和特定的实例数据。
4. **调用实例化绘制函数**：使用 `glDrawArraysInstanced` 或 `glDrawElementsInstanced` 进行绘制。

通过实例化绘制技术，开发者可以显著提高渲染效率，特别是在需要大量重复对象的场景中。
