# Lesson2：提示词工程（精简大纲）

> **目标**：理解 Prompt 如何影响模型行为，掌握 ICL 机制，建立系统化工程方法。

---

## 核心主线

```
概率分布的不确定性 → ICL 机制 → 技术选型 → System Prompt 设计 → 评估迭代
```

---

## 第一部分：本质认知

### 问题：模型为什么不确定？
- 模型 = 概率分布预测器（回顾 Lesson1）
- Prompt 工程 = 收敛概率分布的四种手段：
  1. 上下文约束（缩小空间）
  2. 示例引导（调整分布）
  3. 结构化格式（锁定模式）
  4. COT（延长路径）

### ICL 机制（前沿研究）
- Task Recognition vs Task Learning
- 示例数量边际收益曲线（3-5 个最优）
- 示例质量 > 数量（相似度 + 多样性 + 顺序）

### 常见反模式
| 反模式 | 表现 | 修复 |
|--------|------|------|
| 过度拟人化 | "请认真思考" | 删除情感表达 |
| 指令模糊 | "生成好的代码" | 明确验收标准 |
| 示例过多 | 10+ 个示例 | 精选 3-5 个 |

## 第二部分：技术选型

### 决策树
```
任务复杂度 → 外部知识 → 推理链 → 工具调用 → 技术组合
```

### 核心技术对比
| 技术 | 机制 | 场景 | 成本 | 典型失败 |
|------|------|------|------|----------|
| Zero-Shot | 预训练知识 | 简单任务 | 低 | 超出分布 |
| Few-Shot | ICL 模式识别 | 格式化/分类 | 中 | 示例质量差 |
| COT | 延长推理路径 | 多步推理 | 高 | 简单任务浪费 |
| RAG | 外部知识注入 | 事实准确性 | 中 | 检索质量差 |

### 成本优化
- Few-Shot 边际收益：0→3（质量跃升）、3→5（递减）、>5（负收益）
- 缓存优化：System Prompt + 示例固定前缀 → 成本降 90%

### 结构化输出
- JSON Schema > 自然语言（硬约束 vs 软提示）
- 重试策略：最多 3 次 → 降级为自然语言解析

## 第三部分：System Prompt 设计

### 分层架构
```
身份定义 → 工具资源 → 行为约束 → 输出格式 → 示例
```

### 前沿实践（Coding Agent 案例）
- 工具描述：JSON Schema + 使用示例
- 安全约束：NEVER/ALWAYS 列表
- 反过度工程：信息密度 < 200 tokens/块

### 与 KV Cache 的关系
- System Prompt = 固定前缀 → Prefill 一次，后续复用
- 高频场景：投入更多 tokens 换降本
- 低频场景：简化 System Prompt 减少开销

### 前沿趋势（2024-2025）
- Constitutional AI（原则表达）
- Prompt Compression（LLMLingua）
- Multi-turn System Prompt（动态调整）

## 第四部分：场景化实践

### 代码场景策略矩阵
| 场景 | 策略 | temperature | 验收指标 |
|------|------|-------------|----------|
| 代码生成 | Zero-shot + 格式约束 | 0.2 | 可编译率 > 90% |
| 代码审查 | Few-shot + COT | 0.1 | F1-score |
| 方案设计 | COT + Multi-turn | 0.7 | 覆盖度 |
| Bug 修复 | RAG + COT | 0.2 | 测试通过率 |

### 模板库设计
每个模板包含：
- 适用场景
- 完整示例
- 失败案例 + 修复
- 成本参考

## 第五部分：评估与迭代

### 分层评估体系
| 层级 | 指标 | 工具 | 阶段 |
|------|------|------|------|
| 输出质量 | 准确率/F1 | 自动化测试 | 开发 |
| 系统性能 | TTFT/P95 | APM 监控 | 生产 |
| 经济性 | 单任务成本 | 日志分析 | 生产 |
| 安全性 | 防注入率 | Red Team | 上线前 |

### 迭代闭环
```
定义验收标准 → 初始 Prompt → 测试 20-50 样本 → 失败分析 → 
针对性修改 → 回归验证 → 固定版本
```

### 常见失败模式
| 失败模式 | 根因 | 修复 | 优先级 |
|----------|------|------|--------|
| 输出过载 | 缺少长度约束 | max_tokens | 高 |
| 格式错误 | 示例不够 | 补充示例/Schema | 高 |
| 幻觉 | 缺少知识 | RAG/降温 | 高 |
| 指令漂移 | 上下文累积 | 重申约束 | 中 |

### 前沿工具链
- 开发：PromptFoo（A/B）、LangSmith（trace）
- 生产：LangFuse（可观测）、Helicone（成本）
- 安全：Garak（防注入）
- 优化：DSPy（自动优化）

---

## 六大核心要点

1. **本质**：收敛概率分布，非调参艺术
2. **ICL**：示例质量 > 数量，3-5 个最优
3. **成本**：Output 贵 3-5×，缓存降 90%
4. **分层**：身份→工具→约束→格式→示例（<200 tokens/块）
5. **闭环**：验收标准→测试→失败分析→修改→回归
6. **前沿**：Constitutional AI + Compression + Multi-turn
