# 上下文工程 VS 提示词工程



Context Engineering和Prompt Engineering的目的都是让激发出LLm的能力，不过对比二者：

+ Prompt Engineering主要是激发LLm做好单一件事情，适合处理流程简单的工作。
+ Context Engineering是利用LLm处理更加复杂，更加系统的任务，更加符合这个智能Agent的时代。
