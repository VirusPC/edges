Anthropic推出了一种名为Agent Skills的新方法，通过文件和文件夹为Claude代理提供专业知识。Agent Skills是由指令、脚本和资源组成的文件目录，能够动态加载并扩展Claude的能力，使其从通用代理转变为专用代理。技能设计基于逐步披露原则，使Claude仅在需要时加载相关信息，从而提高效率和可扩展性。此外，技能还可以包含可执行代码，以实现确定性和高效性。开发技能需要观察Claude的实际任务表现，迭代优化，并注意安全性，确保技能来源可信。未来，Anthropic计划进一步支持技能的创建、编辑和共享，甚至探索代理自主创建和优化技能的可能性。

### 关键点
+ Anthropic推出Agent Skills，通过文件和文件夹为Claude代理提供专业知识，使其从通用代理转变为专用代理。
+ 技能设计基于逐步披露原则，Claude仅在需要时加载相关信息，提高效率和可扩展性。

+ 开发技能需要通过观察Claude的任务表现来优化，并注意技能的安全性和可信来源。

### 以下是该网页主要内容的总结：
+ **Agent Skills 是 Anthropic 推出的模块化能力扩展方式**，通过文件夹（包含 SKILL.md 文件和相关资源）将专业知识和操作流程封装，赋能 Claude 等 AI agent实际处理复杂任务。
+ **技能目录结构**：每个技能包含 SKILL.md（含 YAML 元数据：name、description）、可选的额外说明/脚本文件（如 reference.md、forms.md），实现了按需加载，多层次“渐进式披露”上下文。
+ **应用示例**：如 PDF 编辑技能可让 Claude直接填写表单，利用外部脚本高效、可重复地执行操作（比如 Python 脚本进行字段提取）。
+ **技能生命周期和开发建议**：
    - 通过实际任务发现 agent能力缺口，逐步补充技能。
    - 技能内容多时建议拆分成多文件，提高灵活性和效率。
    - 关注元数据的命名和描述，这些会支持 Claude 判断是否触发技能。
    - 联合 Claude实际迭代、反思并完善技能，记录成功经验和常见错误到技能文件中。
+ **安全注意事项**：警惕技能中恶意代码或外部依赖，选用可信来源并审核内容，避免安全风险。
+ **未来规划**：Agent Skills 已支持 Claude 所有平台，后续将增加创建、分享、使用技能的新功能，推动 agent自主生成和优化技能。

整体，Agent Skills让企业或个人无需为每个场景单独开发 agent，只需编写和分享技能文件，即可让 Claude按需进阶为业务专用 agent。[1]
