# PBR

PBR的范畴（Scope of PBR）：寒霜(Frostbite)引擎在SIGGRAPH 2014的分享《Moving Frostbite to PBR》中提出，基于物理的渲染的范畴，由三部分组成：

+ 基于物理的材质（Material）
+ 基于物理的光照（Lighting）
+ 基于物理适配的摄像机（Camera）





PBR 由直接光照和间接光照组成。

判断一种PBR光照模型是否是基于物理的，必须满足以下三个条件：

+ 基于微平面(Microfacet)的表面模型。
+ 能量守恒。
+ 应用基于物理的BRDF。
