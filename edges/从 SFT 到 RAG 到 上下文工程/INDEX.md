梳理大模型在企业应用中的演进路线，其实就是一部”如何正确处理领域知识与业务逻辑”的认知升级史。将这段历程体系化地提炼，可以清晰划分为以下四个核心范式阶段：
阶段一：2023 年上半年 — 狂热的”知识灌注”期
核心理念： 把大模型当”学生”，试图通过持续预训练（CPT）和监督微调（SFT）把企业规章、业务文档、垂直领域知识直接”烤”进模型的权重参数里。
技术手段： 借助 LLaMA 等开源模型和 LoRA 等低成本适配技术，一部分团队用领域语料做 CPT 注入知识，另一部分团队大量构造”文档→QA 对”做 SFT 指令微调——而更多团队混淆了二者的边界，该用 CPT 的场景错用了 SFT。
工程痛点（交学费期）：
	1.	严重幻觉： 无论 CPT 还是 SFT，知识都没有被可靠地记住，模型只是学会了”用专业且自信的语气胡说八道”。
	2.	知识过时： 企业数据（如产品报价）天天变，重新训练成本极高且严重滞后。
	3.	灾难性遗忘： 强行注入垂类知识后，模型原本的通用推理和代码能力断崖式下跌。
结论： 业界在这个阶段交了学费，开始意识到：CPT 可以建立领域语感，但无法精确记忆事实；SFT 的核心价值在于行为对齐，而非知识注入。试图用训练来解决”事实供给”问题，方向本身就错了。
阶段二：2023 年底至 2024 年中 — 务实的”外挂大脑”期（RAG 与 Tool Calling 崛起）
核心理念： 不让模型”背”知识，让它学会”查”知识和”用”工具。
技术手段：
	∙	RAG（检索增强生成）： 将企业知识库切块存入向量数据库，用户提问时先检索相关片段，拼接到 Prompt 中让模型总结，从根本上解决了幻觉和知识实时更新的问题。
	∙	SFT 的角色重塑： SFT 不再承担知识注入的使命，转向为 Agent 能力服务——训练模型准确判断何时调用哪个工具、如何构造调用参数、如何稳定输出结构化格式，这是 Function Calling / Tool Calling 可靠运行的基础。
工程痛点： 朴素 RAG 的文本切块（Chunking）容易丢失上下文语义，检索召回率（Recall）成了制约业务效果的最大瓶颈。
阶段三：2024 年中至年底 — 检索增强的深水区（Agentic RAG 与 Graph RAG）
核心理念： 单纯的”切块→向量检索→拼接”已经触顶，需要更智能的检索策略。
技术手段：
	∙	Graph RAG： 以微软 2024 年 7 月发布的 GraphRAG 论文为标志，将知识库预处理为实体-关系图谱，用图结构捕获朴素向量检索丢失的跨文档关联和全局语义。
	∙	Agentic RAG： 让 Agent 自主决定检索策略——先判断是否需要检索、选择哪个知识源、是否需要追问或多轮检索，再整合结果，形成”检索也是 Agent 行为”的范式。
意义： 这是从朴素 RAG 到下一阶段”上下文工程”之间的关键过渡，解决了大规模知识库场景下召回质量的系统性问题。
阶段四：2024 年下半年至今 — “超长上下文 + RL 推理增强”期
核心理念： 暴力美学与深度思考并存。知识供给转向超大上下文窗口，复杂任务转向强化学习（RL）激发的推理能力。
技术手段：
	∙	Context Engineering（上下文工程）在中小规模文档场景取代传统 RAG： 随着百万 Token 原生窗口和 Context Caching 成本骤降，面对几十万字的 API 文档或整个前端代码库，直接全量塞入 Prompt 让模型自行提取关联信息，效果往往优于复杂的向量检索流水线。但需要注意：企业知识库动辄数百万到数十亿 Token，远超任何上下文窗口，大规模知识管理仍然依赖检索体系。
	∙	Agent 架构成熟： 工作流编排（如 n8n）与 System Prompt 结合处理固定的企业 SOP 流程；AI Coding Agent 开始在真实开发环境中大规模落地。
	∙	RL 走向台前： 以 o1（2024 年 9 月）、DeepSeek-R1（2025 年 1 月）为代表的推理模型，RL 阶段不以记忆业务事实为目标，而是集中训练模型”如何规划多步任务”“如何自我纠错（Self-Correction）“以及”如何构建严谨的思维链（CoT）”。
SFT 的终极定位： 在这个阶段，SFT 变成了打磨前端体验和 Agent 稳定性的精细工程，比如微调一个专有小模型，让它专门负责高速、零错误地调度某个特定内部 SDK。

一句话总结这条路线：
从”试图改变模型的脑结构（CPT/SFT 注入事实）“→ 转向”给模型发一本参考书（RAG）并教它自己翻书（Agentic RAG）“→ 再到如今”给模型一张无限大的书桌（超长上下文）并重点培养它解决复杂问题的逻辑（RL）”。
这是一个非常典型的、由工程落地痛点倒逼出来的技术演进过程。​​​​​​​​​​​​​​​​
