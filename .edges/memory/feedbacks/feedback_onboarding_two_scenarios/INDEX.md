用户确认，场景描述用户想做的事，流程描述接入的执行路径。多个场景可以使用同一条流程。

**Why:** 何时用需要让 Agent 识别真实需求，执行部分需要给出清楚的操作路径。二者分开组织，避免把流程名称当成全部使用场景。

**How to apply:** 何时用列出项目上下文、模块维护、个人大脑、跨项目方法库、团队共享库等场景，并映射到已有项目添加 edges harness 目录或创建独立 edges harness 仓库。独立仓库默认包含 GitHub 建仓与首次推送，明确选择 private/public；用户要求仅本地时跳过远程步骤。文档保持简短。
