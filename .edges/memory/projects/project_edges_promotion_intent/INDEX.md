Edges 对外推广先完成核心价值实验、Skills 接入梳理和场景案例准备；这一组主任务与子任务统一由 Edges 框架仓跟踪。这是用户在 2026-10-27 明确的方向与任务归属。

**Why:** 用户先将“宣讲”澄清为“推广”，再提出先把核心价值点跑完实验、带着数据说话，重新梳理 Skills 方便别人接入，并考虑面向具体场景写使用案例。任务共同服务于 Edges 产品推广，不能因为最终文章可能归个人内容仓，就把推广主任务和文章子任务拆到另一份看板。

**How to apply:**
- 先让对外核心价值主张对应到实验或能力验收，保留对照、指标、实际结果与适用边界；不能把链路冒烟或全文注入的结果直接表述为真实 Agent 按需使用 Edges 的收益。
- 梳理对外 Skills 的组织、发现与接入流程，以外部使用者能接入并完成真实任务为目标；衔接已有的按模块收敛 Skill 待办。
- 围绕明确使用场景准备案例文章，将读者问题、实际过程、结果和接入步骤连起来；未经实测的演示方案不能写成已有用户成功案例。
- 主任务、实验、Skills、接入验收、案例素材与文章子任务都留在框架仓，父子关系与依赖使用仓内链接。文章产物的存放位置按目标内容仓的规则另行处理，不反过来决定任务归属。
- 具体实验范围、模型、预算、阈值、Skill 映射、文章选题、数量与发布渠道尚未确定；助手给出的候选不视为已定方案。
